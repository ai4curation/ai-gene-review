**Title:** PAINT/IBA export coverage for VEuPathDB pathogen and vector reference proteomes

**Body:**

We are using GO IBA annotations to triage VEuPathDB eukaryotic pathogen and vector proteomes for GO review. The following VEuPathDB organisms have UniProtKB proteins with PANTHER family cross-references but no IBA rows in QuickGO:

- Plasmodium vivax Sal-1 (`PLAVS`, taxon `126793`)
- Plasmodium berghei ANKA (`PLABA`, taxon `5823`)
- Toxoplasma gondii ME49 (`TOXGM`, taxon `508771`)
- Cryptosporidium parvum Iowa II (`CRYPI`, taxon `353152`)
- Trypanosoma cruzi (`TRYCR`, taxon `5693`)
- Leishmania donovani (`LEIDO`, taxon `5661`)
- Babesia bovis T2Bo (`BABBO`, taxon `5865`)
- Babesia microti strain RI (`BABMR`, taxon `1133968`)
- Theileria annulata strain Ankara (`THEAN`, taxon `5874`)
- Theileria parva strain Muguga (`THEPA`, taxon `5875`)
- Encephalitozoon cuniculi GB-M1 (`ENCCU`, taxon `284813`)
- Encephalitozoon intestinalis ATCC 50506 (`ENCIT`, taxon `876142`)
- Enterocytozoon bieneusi H348 (`ENTBH`, taxon `481877`)
- Nematocida parisii ERTm3 (`NEMP3`, taxon `935791`)
- Nakaseomyces glabratus CBS 138 (`CANGA`, taxon `284593`)
- Cryptococcus neoformans H99 (`CRYN9`, taxon `235443`)
- Aedes aegypti (`AEDAE`, taxon `7159`)

Against GO release 2026-08-05 and PANTHER 19.0, these exact taxa are absent from `go-reference-species.yaml`, the PANTHER supported-genomes API, and the PANTHER PAINT leaf GAF snapshot 2026-08-28. Querying each exact taxon and its species taxon with `taxonUsage=descendants` in QuickGO also returns zero IBA rows, so this does not look like a strain-only query mismatch.

Can GO/PANTHER either add PAINT reference-proteome and IBA export coverage for these VEuPathDB organisms, or document why these current pathogen/vector proteomes are intentionally out of scope? Candida/Nakaseomyces glabratus is a useful edge case: GO already publishes `CANGA-mod` and `CANGA-uniprot` GAF/GPAD/GPI files, but neither carries PAINT/IBA rows because the PAINT reference set includes `CANAL` rather than `CANGA`.

A separate VectorBase export lead is worth checking too: Ixodes scapularis (`IXOSC`, taxon `6945`) is present in the same PAINT leaf GAF with 25034 IBA rows, but the exact QuickGO query currently returns only 229 IBA rows.
