# Global IEP atlas

Generated by [`iep_global_atlas.py`](iep_global_atlas.py). The complete set of **25,401** annotations that a GAF labels IEP, downloaded from QuickGO with `evidenceCode=ECO:0000270&evidenceCodeUsage=descendants` and then filtered to `GO EVIDENCE CODE == IEP`. This is the denominator for the review-driven sample measured in [iep-corpus-survey.md](iep-corpus-survey.md).

GOA snapshot: **2026-07-27** ([`data/global_iep_annotations.tsv`](data/global_iep_annotations.tsv), committed so the figures below stay reproducible as GOA moves; delete it to re-download). GO closure computed against OAK adapter `sqlite:obo:go` (release date unavailable).

One set of figures is **not** frozen by that snapshot: the [IEP-dependence shares](#how-dependent-is-each-term-on-iep) divide the snapshot's IEP count for a term by a *live* QuickGO count of all annotations to that term, so they drift as GOA grows.
