Canonical activin receptor-SMAD signaling pathway module

Mature activin agonists organize type II/type I serine/threonine kinase receptor complexes. Type II receptors activate type I receptors, which phosphorylate activin-branch R-SMADs; R-SMAD/co-SMAD complexes then regulate nuclear transcription. Human activin A and native Drosophila Actbeta provide complementary examples, with ligand-specific receptor usage and shared BMP components explicitly distinguished.
