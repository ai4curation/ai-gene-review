Executable models

Modules describe pathways as curated knowledge. Some of them can also be run: read as a Boolean network, a kinetic model, a flux model or an agent-based simulation. Each model listed here is attached to a module under executable_models. A model derived from the module is generated from its curated connections and never edited by hand, so fixing the model means fixing the module. An external model is a published one that serves as evidence for the module's wiring. Derived Boolean models run in your browser, and their curated scenarios are checked in validation.

ERK cascade as a Boolean network

Module: ERK1/2 (Ras-RAF-MEK-ERK) MAPK cascade module
The module's connections read as a signed regulatory graph, translated by ai-gene-review module-to-bnet with the default rule (active when any activator is active and no inhibitor is). Every rule comes from the module's connections; nothing is edited in the network itself. The scenarios are checked by exhaustive asynchronous attractor enumeration in validation, so a change to the wiring that alters any of these behaviours fails loudly.

MAPK network and cancer cell fate decisions (Grieco 2013)

Module: ERK1/2 (Ras-RAF-MEK-ERK) MAPK cascade module
Published logical model of the MAPK network (BBM-070 in the Biodivine Boolean Models corpus). Used as a calibration source for this module's wiring through a reviewed id-mapping; its ERK ⊣ RAF and RSK ⊣ SOS feedbacks prompted the feedback connections curated into this module. Its cyclic attractor under growth-factor input is the behaviour the derived model's sustained-stimulus scenario reproduces.

Maud kinetic model of the methionine cycle (biosustain)

Module: Methionine (S-adenosylmethionine) cycle module
Bayesian kinetic model of the methionine cycle from the biosustain Maud project. Only its regulation tables (allostery, competitive inhibition) are ingested, as evidence for this module's regulatory connections through a reviewed id-mapping; stoichiometry, kinetics and priors are not used.
