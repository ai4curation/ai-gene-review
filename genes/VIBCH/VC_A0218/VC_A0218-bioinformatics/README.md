# VC_A0218 (Q9KMV0) sequence analysis

Two questions, both answered by pairwise global alignment:

1. Is Q9KMV0 the same protein as the *Vibrio cholerae* lecithinase Lec that
   Fiore et al. 1997 (PMID:9234762) cloned and assayed from strain E7946
   (GenBank U50074 / AAA92960.1)?
2. How closely is Q9KMV0 related to the experimentally characterised
   *V. parahaemolyticus* thermolabile haemolysin (Tlh / lecithin-dependent
   haemolysin, LDH), and how distant is it from *P. aeruginosa* EstA, the sole
   seed of the PANTHER PTN005219546 IBD for GO:0008610?

Reproduce with:

```bash
./fetch_seqs.sh          # downloads sequences into data/ from UniProt + NCBI
uv run python compare.py # prints the identity table in RESULTS.md
```

`data/` is regenerated by `fetch_seqs.sh` and is not meant to be edited.
