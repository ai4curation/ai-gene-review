Gene Description

PutA from Geobacter sulfurreducens PCA is a class 2A bifunctional proline-catabolic flavoenzyme. It couples FAD-dependent oxidation of L-proline to pyrroline-5-carboxylate with NAD-dependent oxidation of glutamate semialdehyde to L-glutamate. A tunnel between the active sites supports substrate channeling, and the protein forms a domain-swapped dimer. Its quinone-binding site supports a peripheral membrane-associated catalytic role. This architecture lacks the N-terminal transcriptional-repressor module found in class 1C PutAs.

Core Functions

Oxidizes L-proline to P5C through the FAD-dependent PRODH module, with quinone reoxidation supported using model acceptors. The reaction is coupled by an internal channel to the GSALDH module. Direct biochemical evidence is from recombinant PCA Q746X3; the endogenous quinone is not identified.
