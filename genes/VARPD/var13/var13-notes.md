# Curation Notes: var13 (A0A0N9M354) in Variovorax paradoxus

## Overview
- **UniProt ID:** `A0A0N9M354` (`A0A0N9M354_VARPD`, 261 aa)
- **Gene symbol / GenBank protein:** `var13` (`ALG65348.1`, `EMBL:KT362218`)
- **Organism:** *Variovorax paradoxus* strain P4B (`NCBITaxon:34073`)
- **Function:** Cytoplasmic FhuF-family ferric-siderophore reductase (`PF06276` / `TIGR03951` / `IPR008090`).

## Domain Architecture & Physiological Role
- **Domain organization:** FhuF ferric iron reductase domain (`PF06276` / `TIGR03951` / `IPR008090`) with an IucA/IucC-like core fold (residues 66–206) and C-terminal `[2Fe-2S]` cluster-binding motif.
- **Evidence:** Co-encoded in the *V. paradoxus* P4B `var` cluster (`KT362218`, [PMID:26412281]); catalyzes reductive release of $	ext{Fe(II)}$ from imported ferric-variobactin hydroxamate complexes in the cytoplasm ([PMID:38590537]).
