Gene Description

Var4 (ALG65339.1; orthologous to VarG in Variovorax sp. H002 and Variovorax boronicumulans) is a 2,345-amino-acid hybrid modular type I polyketide synthase / nonribosomal peptide synthetase (PKS/NRPS) with an embedded C-terminal TauD/TfdA-family Fe(II)/2-oxoglutarate-dependent dioxygenase domain, encoded in the variobactin (var) biosynthetic gene cluster of Variovorax paradoxus strain P4B (GenBank KT362218). Var4 comprises an N-terminal beta-ketoacyl synthase domain (residues 16-450, PF00109 / PF02801 / PROSITE PS52004), an acyltransferase domain (PF00698 / IPR001227), an NADPH-dependent ketoreductase domain (PF08659 / IPR013968), a 4'-phosphopantetheinylated acyl/peptidyl carrier protein domain (residues 1433-1508, modified at Ser1468; PF00550 / PROSITE PS50075 / IPR020806), an NRPS LCL-type condensation domain (PF00668 / IPR001242), and a C-terminal TauD-like beta-aspartyl hydroxylase domain (PF02668 / IPR003819). During variobactin/variochelin assembly, Var4 elongates the N-acyl-arginine starter unit with a malonate/methylmalonate ketide unit and reduces the beta-keto group to form the gamma-amino acid moiety (4-amino-7-guanidino-3-hydroxy-2-methylheptanoate), and catalyzes beta-hydroxylation of the adjacent aspartate monomer to generate the photoreactive beta-hydroxyaspartate (Hya; reported as L-erythro-Hya for TauD-type hydroxylases in PMID:38590537, though L-threo-Hya was earlier reported for variochelin A in PMID:27023373) iron-chelating group.

Core Functions

Hybrid type I polyketide synthase / nonribosomal peptide synthetase module (KS-AT-KR-ACP-C) that elongates the N-acyl-arginine starter unit with a malonate/methylmalonate ketide unit, reduces the beta-keto intermediate to a 3-hydroxy group, and condenses it with the downstream peptide chain during variobactin siderophore biosynthesis.

Curation Notes: var4 (A0A0N7FMV9) in Variovorax paradoxus

Overview

  • UniProt ID: A0A0N7FMV9 (A0A0N7FMV9_VARPD, 2,345 aa)
  • Gene symbol / GenBank protein: var4 (ALG65339.1, EMBL:KT362218; orthologous to varG in Variovorax sp. H002 and V. boronicumulans)

  • Function: Hybrid type I polyketide synthase / nonribosomal peptide synthetase (PKS/NRPS) with an embedded C-terminal TauD/TfdA-family Fe(II)/2-oxoglutarate-dependent beta-aspartyl dioxygenase domain.

  is a 2,345-amino-acid hybrid modular type I polyketide synthase / nonribosomal peptide synthetase (PKS/NRPS)
  with an embedded C-terminal TauD/TfdA-family Fe(II)/2-oxoglutarate-dependent dioxygenase domain, encoded
  in the variobactin (var) biosynthetic gene cluster of Variovorax paradoxus strain P4B (GenBank KT362218).
  Var4 comprises an N-terminal beta-ketoacyl synthase domain (residues 16-450, PF00109 / PF02801 / PROSITE
  PS52004), an acyltransferase domain (PF00698 / IPR001227), an NADPH-dependent ketoreductase domain (PF08659
  / IPR013968), a 4'-phosphopantetheinylated acyl/peptidyl carrier protein domain (residues 1433-1508,
  modified at Ser1468; PF00550 / PROSITE PS50075 / IPR020806), an NRPS LCL-type condensation domain (PF00668
  / IPR001242), and a C-terminal TauD-like beta-aspartyl hydroxylase domain (PF02668 / IPR003819). During
  variobactin/variochelin assembly, Var4 elongates the N-acyl-arginine starter unit with a malonate/methylmalonate
  ketide unit and reduces the beta-keto group to form the gamma-amino acid moiety (4-amino-7-guanidino-3-hydroxy-2-methylheptanoate),

  earlier reported for variochelin A in PMID:27023373) iron-chelating group.
