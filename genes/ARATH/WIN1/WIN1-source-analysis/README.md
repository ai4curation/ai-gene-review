# WIN1 in the PMID:28887381 primary supplement

Original publisher-deposited spreadsheets were obtained by the normal Europe PMC supplementaryFiles endpoint during the preceding sulfate audit and reused without modification. The script downloads that same archive and reproduces a complete target-row extraction; the JSON preserves source filenames, SHA-256 hashes, headers and rows.

Supplemental Table S1, Mapp sheet, row 383 identifies AT1G80600.1 / WIN1. Subacon localization is plastid, and both True membrane and Dual Localized are empty. The table does not independently establish a mitochondrial localization. Its plastid label is an imported SUBAcon classification, not a new targeting assay. Chloroplast localization is independently demonstrated by functional GFP complementation and microscopy in PMID:23321422. These findings do not exclude an additional mitochondrial pool.
