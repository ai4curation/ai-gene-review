# NAGK in the PMID:28887381 primary supplement

Original publisher-deposited spreadsheets were obtained by the normal Europe PMC supplementaryFiles endpoint during the preceding sulfate audit and reused without modification. The script downloads that same archive and reproduces a complete target-row extraction; the JSON preserves source filenames, SHA-256 hashes, headers and rows.

Supplemental Table S1, Mapp sheet, row 897 identifies AT3G57560.1 / NAGK. Subacon localization is plastid, True membrane is True, and Dual Localized is empty. The independent sucrose-gradient protein and peptide profiles also detect NAGK. These data support a membrane-associated pool but do not independently identify a cytosolic compartment or a particular chloroplast membrane. The SUBAcon label is an imported localization classification, not a new organelle-targeting experiment. Direct chloroplast-stromal evidence comes from PMID:16377628.
