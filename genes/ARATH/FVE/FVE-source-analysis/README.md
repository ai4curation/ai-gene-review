# FVE in the PMID:28887381 deposited proteomics tables

The publisher-deposited supplementary ZIP was retrieved through https://www.ebi.ac.uk/europepmc/webservices/rest/PMC5672003/supplementaryFiles. The reproducible `extract_membrane_tables.py` searches all sheets of all seven original XLSX files for AT2G19520, records complete matching rows and SHA-256 hashes, and writes `membrane-table-extraction.json`. No spreadsheet or publication text was edited.

In Supplemental Table S1, `supp_RA117.000276_4895_0_supp_4978_88s80d.xlsx`, the Mapp sheet Excel row 432 identifies P1_AT2G19520.1 / AT2G19520.1, FVE/ACG1/MSI4/NFC4. The Subacon localization field is nucleus. The True membrane and Dual Localized fields are empty. Its apparent mass is approximately 51.83–54.30 kDa. The S1 file SHA-256 is ab21f9498047861da42a70ea6bf93330600a5d36933c941fcbd8ada87c8dc28e.

The target also occurs in raw protein and peptide profiles. In `supp_RA117.000276_4895_0_supp_4980_88s80d.xlsx`, Raw Sucrose protein profiles row 2053 again lists nucleus. No target match was found in the other five XLSX files, including the oligomeric membrane-complex and dual-localization summary tables. The source experiment profiles broadly prepared microsomes and explicitly contains proteins assigned to different compartments; detection in this fraction does not identify a mitochondrial pool. These results establish target detection and the source's nuclear classification, not an experimental exclusion of every possible mitochondrial pool.

## Independent nucleolar corroboration and remaining access limits

PMID:15608277 (Brown et al., AtNoPDB; DOI10.1093/nar/gki052) was fetched normally with full text. Figure1 is a screenshot of the primary localization database; the publisher PDF text extraction at https://academic.oup.com/nar/article-pdf/33/suppl_1/D633/7621816/gki052.pdf explicitly contains the row `At2g19520 | WD-40 repeat protein (MSI4) | DNA interacting protein | NU:no:NAS`. The full article defines NU/nu as nucleoplasm, NO/no as nucleolar, and NAS/nas as nucleolus-associated structures, with uppercase/lowercase denoting strong/weak labeling. Thus the target has a predominant nucleoplasmic signal together with weaker nucleolar and associated-structure signal. This corroborates the original15496452 nucleolar assertion without inventing a nucleolar biochemical function. The target row was read from the publisher's indexed PDF extraction; the figure JPEG could not be independently downloaded (403/404), so no claim of visual inspection is made. The normally fetched full text contains the figure caption and code definitions but does not OCR the target row.

The original15496452 and25293756 supplementary-file endpoints returned non-ZIP responses; reproducible retrieval attempts and access errors are recorded in `extract_other_localizations.py` and the corresponding JSON records. Their main texts were inspected but do not name the FVE target. The cytoplasmic15610358 GFP dataset remains abstract-only. The two specific cytoplasmic/cytosolic target calls therefore remain unresolved in this audit rather than being rejected because of the established nuclear function.
