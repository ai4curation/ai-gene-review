# Q05085 consolidation provenance

`legacy-reviews.json` preserves both pre-consolidation parsed review documents and SHA-256 hashes for their files. It is historical curation provenance, not independent biological support or a GOA citation. `payload-projection.json` maps all 14 CHL1 and 19 NPF6.3 row occurrences onto 19 current-GOA rows. Every original asserted payload field is identical; six CHL1 rows acquire only supporting_entities metadata already supplied by the newer normal fetch.

The current raw NRT1.1 records were retrieved normally using Q05085 and an NRT1.1 file alias. Old raw files and unrelated Q9LUJ8 prediction artifacts are preserved. No prediction or GOA file is used as functional evidence. Scientific action differences are reconciled in NRT1.1-notes.md and the canonical review, with exact source/assay limits.
