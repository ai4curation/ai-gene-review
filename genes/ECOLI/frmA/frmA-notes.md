# frmA (E. coli K-12, P25437) review notes

2026-11-11. Reviewed as an exemplar for the glutathione-dependent formaldehyde
detoxification module.

- Deep research: no deep-research provider credentials were available in this
  session, so no `-deep-research-*.md` file was generated. The review rests on
  the cached publications and the UniProt record.
- Purified FrmA is a zinc homodimer with 60 U/mg toward
  S-(hydroxymethyl)glutathione + NAD+ [PMID:1731906 "specific activity of 60 units/mg toward S-(hydroxymethyl)glutathione and NAD+ as substrates"].
- Glutathione-independent oxidation of normal alcohols is a secondary
  activity [PMID:1731906 "catalyzes the oxidation of normal alcohols (ethanol, octanol, 12-hydroxydodecanoate) in a reaction that is not GSH-dependent"];
  kept as non-core.
- GSNO reductase: the GSNO-metabolizing activity purified from E. coli is
  the same enzyme [PMID:11260719 "show that it is the glutathione-dependent formaldehyde dehydrogenase"].
- NADP+ row (GO:0106321, EXP): the abstract only states NAD+; deferred to the
  curator but kept non-core.
- Cytoplasm rows MODIFY to cytosol, which is carried by IDA/HDA.
