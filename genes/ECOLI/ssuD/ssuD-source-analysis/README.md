# Native SsuD heat-response evidence

PMID:24580753, Figure 5A, was inspected directly on 2026-10-26. The ssuD mutant is the fourth labeled deletion after wild type (following clpS, copA and frlB). Its heat-survival bar is about one fifth of wild type, while plasmid complementation returns survival near wild type. Oxidative and osmotic controls remain near wild type. This supports the existing response-to-heat annotation as non-core; no protective biochemical mechanism is asserted.
