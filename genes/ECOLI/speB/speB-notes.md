# speB (P60651) curation notes

Deep research: no provider run (no API keys in this session); the review was built
from the Swiss-Prot record and the cached publications.

- Purified AUH converts agmatine to putrescine (Km 1.2 mM).
  [PMID:3081491 "The Km of purified AUH for agmatine is 1.2 mM; the pH optimum is 7.3."]
- Mn2+ essential. [PMID:10329468 "Manganese-free species, obtained by treatment with
  EDTA and guanidinium chloride (3 M), were active only in the presence of added Mn2+."]
- Hexamer by SEC and crystallography. [PMID:33857156 "The elution profile from SEC
  suggested that SPEB was a hexamer, as expected"]
- PANTHER PTHR11358:SF26 is shared with guanidino-acid hydrolases (P. aeruginosa GbuA,
  GpuA), so the subfamily alone does not identify agmatinase; the HAMAP MF_01418 SpeB
  rule and the direct assays do.
