# erg7B notes

## 2026-11-22 re-review

- Reviewed *Aspergillus fumigatus* erg7B as a true lanosterol synthase in
  PTHR11764:SF20.
- UniProt cites PMID:18191972 as functional support for the A. fumigatus
  ergosterol biosynthesis module that contains both erg7A and erg7B.
- PMID:42478844 shows erg7A is dominant but erg7B can rescue erg7A deficiency
  when overexpressed, supporting a non-primary but real lanosterol-synthase
  capacity.
- The same SF20 subfamily also contains HelA, so SF20 alone is not enough to
  license PAINT transfer; the family sidecar now records a leaf-level HelA
  exception instead of pruning erg7B.
- Retained the inferred lanosterol synthase, ER membrane, lipid droplet, sterol,
  and ergosterol annotations.
