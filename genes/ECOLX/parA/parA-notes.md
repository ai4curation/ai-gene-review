# parA (P07620), plasmid prophage P1 partition ATPase

## 2026-10-30: initial review

UniProt files this P1 protein under generic Escherichia coli (taxon 562), hence ECOLX.
GOA had one row: identical protein binding (IPI, PMID:19461582).

- Dimer via N-terminal helix [PMID:19461582] -> MODIFY to protein homodimerization activity.
- ATPase; nucleotide-site mutant inactive for partition even without autoregulation [PMID:8885272];
  ATP-site mutants separate repression from partition [PMID:11532954].
- ATP-dependent non-specific DNA binding, essential for partition [PMID:20659294; PMID:33055234].
- Operator binding (ATP or ADP) needed for repression but not partition [PMID:33055234];
  ADP favours operator binding [PMID:10064607; PMID:19461582].
- Interacts with ParB at parS in an ATP-dependent way [PMID:10064607; PMID:21965538].

Decisions: NEW ATP hydrolysis activity, DNA binding, plasmid partitioning (core); repressor
activity and negative regulation of transcription (non-core).
