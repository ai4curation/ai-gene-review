# parB (P07621), plasmid prophage P1 centromere-binding protein

## 2026-10-30: initial review

UniProt files this P1 protein under generic Escherichia coli (taxon 562), hence ECOLX.
GOA had one row: DNA binding (InterPro IEA).

- parS binding with IHF; A-box/B-box recognition [PMID:8429038]; crystal structures of ParB-parS
  with DNA bridging [PMID:16306995].
- parS-dependent foci near quarter positions, mispositioned without ParA [PMID:10611311].
- Spreading occurs but extensive spreading is not required for partition [PMID:15130136].
- **No CTPase evidence found.** Not proposed; raised as a suggested question. The ParABS module
  likewise asserts the plasmid ParB CTPase only for SopB and KorB.
- Partition role: the original parB mutant papers are not cached, so plasmid partitioning is
  recorded as IDA from the localization study, with the essentiality statement from PMID:8885272.

Decisions: DNA binding MODIFY -> sequence-specific DNA binding; NEW sequence-specific DNA binding
(IDA) and plasmid partitioning (IDA).
