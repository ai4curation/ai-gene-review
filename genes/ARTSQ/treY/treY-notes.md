# treY (Arthrobacter sp. Q36, Q44315) curation notes

- Deep research: no provider API keys were available in this session, so no
  `-deep-research-<provider>.md` was generated. The review rests on the
  Swiss-Prot record, GOA and the cached abstracts of PMID:8605217 and
  PMID:8611744.
- Purified native enzyme activity [PMID:8611744 "catalyzes the conversion of
  maltooligosaccharide into the non-reducing saccharide, maltooligosyl
  trehalose"]; no activity on maltose [PMID:8611744 "The enzyme was specific
  for maltooligosaccharides except maltose"].
- treYZ operon [PMID:8605217 "it is suggested that treYZ constitutes and
  operon"].
- GOA has only electronic rows (InterPro, TreeGrafter PTN002449568, EC/Rhea);
  no experimental GO row exists despite the purified-enzyme paper. The TreeGrafter
  node is not a PAINT IBD node; the PAINT TreY node is PTN008498486, seeded by
  M. tuberculosis P9WQ21.
