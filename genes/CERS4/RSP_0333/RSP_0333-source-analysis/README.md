# Rhodobacter/Cereibacter BcsAB construct identity

The unmodified PDBe SIFTS API responses map PDB 4HG6 chains A and B to Q3J125 (UniProt 1-788) and Q3J126 (UniProt 21-725), respectively, with identity 1.0. The BcsB construct substitutes a PelB signal sequence for its native signal peptide and adds a Met-Gly dipeptide after cleavage. PDB 4P00 independently maps to the same accessions; PDB residue numbering need not equal native UniProt numbering. Provenance URLs and SHA256 values are in provenance.json.

PMID:23222542 Methods explicitly specifies Rhodobacter sphaeroides 2.4.1 genomic DNA, BcsA with a C-terminal 12-His tag, and BcsB residues 21-725 expressed with an alternative signal peptide. These records support direct target attribution, while retaining engineered-construct caveats. Current UniProt calls this organism Cereibacter sphaeroides 2.4.1 and uses species code CERS4; the historical publications use Rhodobacter.

This is accession/construct mapping, not a newly inferred phylogeny or proof of native-cell phenotypes. The gene's raw UniProt record independently contains the PDB cross-references. The pristine annotations and raw hashes are snapshotted in the audit log directory before curation.
