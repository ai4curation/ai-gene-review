# MCT1 (YOR221C, Q12283) notes

- Mitochondrial malonyl-CoA:ACP transacylase (FabD family, EC 2.3.1.39) of mtFAS [UniProt:Q12283 "Reaction=holo-[ACP] + malonyl-CoA = malonyl-[ACP] + CoA;"].
- Identified by homology; disruption -> respiratory deficiency [PMID:9388293 "We disrupted these two genes which in both cases led to a respiratory deficient phenotype"]; [PMID:9388293 "They are presumed to be part of a type-II mitochondrial fatty acid synthase"].
- Mitochondrial in proteomes (PMID:16823961, PMID:24769239).
- Uses malonyl-CoA produced in the matrix by HFA1 [PMID:14761959].
- YeastPathways places MCT1 in cytosolic FAS pathways (PWY3O-10 etc.); in the cytosol malonyl transfer is done by the MPT domain of FAS1. Cytosol RCA rows wrong; MF correct.
