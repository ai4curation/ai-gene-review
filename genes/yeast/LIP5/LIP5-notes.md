# LIP5 notes

Reviewed for the endogenous protein lipoylation module (modules/endogenous_protein_lipoylation.yaml),
as a yeast exemplar of the mitochondrial GcvH (Gcv3) relay route.

## Literature sources

No deep-research provider is configured in this session (no provider API key), so no
`-deep-research-*.md` file was generated. Sources: UniProt record; cached PMID:19570983
(Schonauer et al. 2009, full text), PMID:23960015 (Hermes and Cronan 2013, full text),
PMID:11356580 and PMID:8349643 (abstracts), and the large-scale localization papers.

## Summary

- LIP2 and LIP5 are required for lipoylation of Lat1, Kgd2 and Gcv3; Gcv3 is required for
  Lat1/Kgd2 lipoylation [PMID:19570983].
- Lip2 has octanoyltransferase activity and lacks ligase activity [PMID:23960015].
- Lip3 (AIM22, P47051) acts downstream genetically, but no amidotransfer activity was detected
  for it in vitro (insoluble protein) [PMID:23960015], so it is not used as a module exemplar.
