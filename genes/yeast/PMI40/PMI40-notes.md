# PMI40 notes (P29952, YER003C)

- Type I mannose-6-phosphate isomerase, EC 5.3.1.8, Zn2+ cofactor [UniProt:P29952 "Reaction=D-mannose 6-phosphate = D-fructose 6-phosphate;"] [UniProt:P29952 "Note=Binds 1 zinc ion per subunit.;"].
- Essential for GDP-mannose and Dol-P-Man supply; null requires mannose [PMID:1377774 "Deletion of the PMI40 coding sequence results in a strain requiring D-mannose for growth."] [PMID:1377774 "prevents synthesis of the GDP-mannose and dolichol-phosphate-mannose required for a number of critical mannosyl transfer reactions"].
- Mannose-induced transcription without increased protein [PMID:1377774 "its transcription is increased 12-fold when cells are grown on D-mannose as sole carbon source instead of D-glucose"].
- IDA PMID:8011630: cached abstract describes Candida albicans PMI ("Mercury ions can inhibit Candida albicans phosphomannose isomerase"); activity is not in doubt for Pmi40, so ACCEPT/defer.
- Module note: PMI40 is a branch enzyme (F6P <-> M6P) linking glycolysis to mannosylation and mannose catabolism, not an EMP glycolysis step.
