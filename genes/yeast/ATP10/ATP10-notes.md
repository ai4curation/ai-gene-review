# ATP10 notes

## 2026-10-01 rereview

- Refreshed the yeast ATP10 source files from QuickGO/UniProt. Current GOA has 13 physical rows and newly includes the SGD `GO:0044183 protein folding chaperone` IPI assertion to Atp6 plus the GOC `GO:0006457 protein folding` logical consequence; the prior generic `GO:0005515 protein binding` row from the yeast-human inter-interactome and the obsolete `GO:0051082 unfolded protein binding` row from the Atp6 paper are no longer live in GOA.
- Checked the current PTHR28106 PAINT export. Both ATP10 IBA rows, `GO:0005743 mitochondrial inner membrane` and `GO:0033615 mitochondrial proton-transporting ATP synthase complex assembly`, trace to `PANTHER:PTN001999212`; that ATP10-family node placement is consistent with the direct yeast Atp10 evidence and does not show a paralog-transfer problem.
- `PMID:14998992` is abstract-only in the local cache, but the abstract directly supports the core model: Atp10p is a mitochondrial inner-membrane component for F0 biogenesis, newly synthesized Atp6p can be cross-linked to Atp10p, the interaction is needed for Atp6p incorporation into a partially assembled ATPase subcomplex, and Atp6p is destabilized in an `atp10` null mutant.
- `PMID:2141026` is also abstract-only in the local cache, but it directly supports the original ATP10 function and broad membrane localization: ATP10 is essential for a functional mitochondrial ATPase, ATP10 mutations cause rutamycin-insensitive F0 defects without respiratory-enzyme defects, and the protein associates with the mitochondrial membrane but not with mature F1 or rutamycin-sensitive F1-F0.
- The current `GO:0044183` assertion has a real Atp6 physical-interaction basis but is too foldase-like. Atp10p is best represented as an Atp6-specific F0 assembly/stabilization factor, so the row was marked `MODIFY` to `GO:0140777 protein-containing complex stabilizing activity`; the inferred `GO:0006457 protein folding` row was marked `REMOVE` because it is only a logical consequence of the overbroad MF.
- Follow-up on PR 3722 removed the duplicate standalone `NEW` `GO:0140777` row after the current GOA refresh introduced a live `GO:0044183` source row that can be modified to the same replacement. ATP10's live SGD `GO:0044183` row is an experimental IPI to the Atp6 client, so this review applies the concrete `MODIFY`/logical-IEA `REMOVE` treatment directly and flags PET100 for re-review under the same rule rather than silently following the older PET100 `MARK_AS_OVER_ANNOTATED` precedent.
- The stale xenologous `GO:0005515 protein binding` row from `PMID:27107014` was marked `retired: true` and `REMOVE`: yeast Atp10p binding to human AGTRAP isoform 2 in a large yeast-two-hybrid survey does not support a physiological ATP10 molecular function.
- Searched for newer ATP10/Atp10p yeast papers beyond the cached literature. No 2025-2026 publication was found that changes the mechanistic assignment; newer hits were broad ATP synthase assembly, mitochondrial systems, or non-yeast ATP10-family context rather than direct Saccharomyces Atp10p work.
