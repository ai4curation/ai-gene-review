# DAL3 (YIR032C, P32459) notes

Pathway context: ureidoglycolate lyase (EC 4.3.2.3), (S)-ureidoglycolate -> urea + glyoxylate.

- Historically "ureidoglycolate hydrolase"; UniProt deprecates that name because EC 3.5.1.116 (amidohydrolase, ammonia-releasing) is a different enzyme [UniProt:P32459]. Dal3 releases urea, so DUR1,2 is required downstream.
- Gene isolation [PMID:3915539 "This report describes the isolation of the genes encoding allantoicase (DAL2) and ureidoglycolate hydrolase (DAL3)"]; activity assay [PMID:5965980 title only].
- C-terminal CIII CAAX-like motif [PMID:1776360 "The four carboxy-terminal amino acids of DAL3 product (Cys-Ile-Ile-Ile) are homologous to those (CAAX) previously shown to be the primary structural signal for post-translational farnesylation"]; membrane ISS row left UNDECIDED (motif only, no prenylation/localization data).
- Expression inducer-independent, NCR-sensitive [PMID:1776360].
