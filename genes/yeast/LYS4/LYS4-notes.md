# LYS4 (YDR234W, P49367) notes

Pathway context: LYSINE-AMINOAD-PWY-2, homoaconitase (EC 4.2.1.36).

- Key finding: Lys4 only interconverts cis-homoaconitate and homoisocitrate; homocitrate -> cis-homoaconitate is done by Aco2 [PMID:23106124 "Although we confirmed an essential contribution of homoaconitases from Saccharomyces cerevisiae and Aspergillus fumigatus, these enzymes only catalysed the interconversion between homoaconitate and homoisocitrate."]; [PMID:23106124 "Aco2p specifically and exclusively contributes to lysine biosynthesis"]. GO:0004409 is defined as the homoisocitrate = cis-homoaconitate + H2O reaction, so it fits Lys4 exactly. Module should include ACO2 for the homocitrate dehydratase half-reaction.
- Homology to A. nidulans LysF and Fe-S cysteines [PMID:9268014 "implying that homoaconitase contains such a cluster"].
- Genetics: [PMID:2507177 "complemented simultaneously MO-59-13c lys4, LU75 lys15 and LU32 lys4lys15 (double) mutations of Saccharomyces cerevisiae"].
- Location: mitochondrion [UniProt:P49367; PMID:14562095]. RCA cytosol MODIFY -> mitochondrion. Rsp5 WW-array protein binding REMOVE.
