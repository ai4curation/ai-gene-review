# CIT2 (YCR005C, P08679) notes

- Second functional citrate synthase gene; only cit1 cit2 double mutants are glutamate auxotrophs [PMID:3023912 "the citrate synthase produced from either gene was sufficient for these metabolic roles"].
- Peroxisomal (SKL), glyoxylate cycle [PMID:2181273 "We conclude that citrate synthase encoded by CIT2 is peroxisomal and participates in the glyoxylate cycle."].
- Cryptic N-terminal PTS/MTS [PMID:16877773 "contains a cryptic targeting signal for both peroxisomes (PTS) and mitochondria (MTS)"].
- SCF(Ucc1) degrades Cit2p in glucose; oxaloacetate stabilises [PMID:25982115 "mediates proteasomal degradation of citrate synthase in the glyoxylate cycle"]; cytoplasmic + peroxisomal [UniProt:P08679].
- Possible methylcitrate synthase activity (cit2 cit3 lacks all MCS activity) [PMID:17570335 "suggesting that Cit2p, a peroxisomal isoform, may also have methylcitrate synthase activity"].

Curation: TCA cycle/aerobic respiration/mitochondrial matrix (IBA, RCA) over-annotated for this peroxisomal paralog; core = citrate synthase in glyoxylate cycle (peroxisome, cytosol).
