# beta-tubulin resistance-site input sequences

`beta_tubulin_sequences.fasta` contains translated protein sequences used to
map benzimidazole-resistance codons 167, 198, and 200 onto A2TF56.

- `A2TF56_EF198865_ABM92348`: UniProt `A2TF56` / GenBank `EF198865` /
  protein `ABM92348.1`, submitted from an India benzimidazole-resistant
  isolate.
- `M76493.1_tub8-9_AAA29170`: GenBank `M76493` / protein `AAA29170.1`, the
  H. contortus `tub8-9` cDNA from Geary et al. 1992.
- `MF034043.1_susceptible_isotype1_partial`: GenBank `MF034043` / protein
  `ASV48510.1`, a partial beta-tubulin isotype-1 susceptible allele.
- `Q18817_BEN1`: UniProt `Q18817`, C. elegans BEN-1.

The GenBank records were inspected through NCBI E-utilities in this session,
and the UniProt sequences came from the cached `A2TF56-uniprot.txt` and
`genes/worm/ben-1/ben-1-uniprot.txt` records.
