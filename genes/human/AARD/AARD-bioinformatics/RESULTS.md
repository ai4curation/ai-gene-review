# Are AARD's reported interactors a coherent partner set?

Generated by `analyze_partners.py`. Partner accessions are read from the gene's own
`AARD-goa.tsv`; all protein data is fetched from the UniProt REST API at run time.

## Question

AARD's entire GO record consists of `protein binding` annotations from a single
yeast two-hybrid publication. This tests one specific, falsifiable explanation for
that set: **coiled-coil bias**. Sticky or self-activating preys in Y2H are enriched
for coiled-coil proteins, which associate promiscuously via heptad-repeat surfaces.
If the partners come from unrelated compartments but share coiled-coil
architecture, the assay explains the set better than any function does.
