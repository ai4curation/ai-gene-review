# Manual deep research: PGF

Perplexity was unavailable during preparation of this VEGF-family review, so this file records the manual literature synthesis used to check PGF rows.

- PMID:9467961 shows that PlGF binds FLT1/VEGFR1, stimulates DNA synthesis in FLT1-expressing porcine aortic endothelial cells, and activates MAP kinase downstream of FLT1.
- PMID:14684734 provides structural support for PlGF binding to VEGFR1 domain 2.
- PMID:11329059 supports a pathological angiogenesis role for PlGF by showing that Pgf loss impairs angiogenesis in adult ischemia, inflammation, wound healing and cancer models.
- PMID:21215706 links PlGF down-regulation to tumor macrophage polarization and vessel normalization, a tumor-microenvironment output outside core FLT1 ligand binding.
- The PMID:20660291 cached abstract does not resolve the seeded PlGF-FLT1 IPI row, so that row is modified to FLT1/VEGFR1 binding using direct PlGF evidence rather than treated as pair-specific proof from the Gremlin/VEGFR2 abstract.
