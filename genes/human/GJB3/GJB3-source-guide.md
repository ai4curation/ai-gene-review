# GJB3 source guide

The [review](GJB3-ai-review.yaml) evaluates all 26 incoming contexts. The [companion](GJB3-external-evidence.md) separates original observations, short source excerpts, inference and access limits; the [notes](GJB3-notes.md) record biological synthesis and the manual research method.

The [archive](GJB3-context-archive.json) preserves the original QuickGO objects, forecast/native mapping and exact 270-residue product. These original objects retain upstream fields and grouped provenance beyond the flat GOA export. The archive is an immutable source snapshot, not a second set of curation decisions. The [evidence manifest](GJB3-source-evidence.yaml) identifies the archive, source files and excerpt locations.

The source closure contains 17 publications, two Reactome entries and three PTHR11984 files. Cache-availability flags describe the genuine cached files; external original access is recorded separately in the reference notes. Curation-session and validation outcomes belong to the append-only history and actual CI records.
