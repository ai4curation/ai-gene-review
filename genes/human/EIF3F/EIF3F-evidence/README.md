# EIF3F database evidence replay

Run `python3 reproduce.py` from this directory (or pass its full path). Python 3 standard library is sufficient; no network, installation or repository environment is used. Keep `database-inputs.zip`, `inputs.json`, `propagation.py` and `results.json` beside the entrypoint. The replay verifies the archive and every exact member hash before parsing, rejects unsafe/duplicate names and symlinks, and does not extract to the filesystem. Missing input or changed hashes fail explicitly. `--write NEW.json` creates a new result file exclusively; it never replaces the saved result.

The archive contains authentic database/API records and released data tables, not article bodies or figure images. It includes IntAct, UniProt, QuickGO, Reactome, PANTHER tree/MSA, PAINT IBD, UniRule/ARBA, InterPro, ec2go, OpenCell and NDEx inputs. `inputs.json` gives exact hashes and acquired URLs where recorded. `original-locators.json` separately identifies unbundled publications, public routes, cache hashes and the sections actually inspected.

The algorithm recomputes full-context GOA joins, interaction identities/features, curated component paths, target table selections, ancestral IBD traces, aligned reference identities, rule applicability and experimental donor records. It preserves self-interaction side matching and does not treat donor count or target self-donation as weakness. It does not rerun experiments or decide annotation actions. Positive-only interaction tables cannot support a global absence claim. Missing original Methods remain explicit scientific limits even when a normal cache has a true full-text flag.
