# SLC16A5 (MCT6) curation notes

- UniProt O15375, "Proton-linked monocarboxylate transporter" [file:human/SLC16A5/SLC16A5-uniprot.txt CC:FUNCTION]; the lactate/pyruvate/ketone FUNCTION detail is By-similarity (ECO:0000250), not experimental. Historical names MCT6/MCT5; HGNC SLC16A5. Cloned by Price, Jackson & Halestrap 1998 [PMID:9425115].
- Demonstrated activity is xenobiotic drug transport: MCT6 transports bumetanide, nateglinide, probenecid and prostaglandin F2-alpha (Murakami 2005, Kohyama 2013, Jones 2017), reviewed in Felmlee et al. 2020 [PMID:32144120 "MCT6 has been shown to transport a small set of xenobiotics: bumetanide, nateglinide, probenecid"]. These are all monocarboxylates, so GO:0008028 monocarboxylate transporter activity is experimentally supported for this member (unlike the orphan siblings); classical lactate/pyruvate transport is not demonstrated.
- Review: GO:0008028 ACCEPT (demonstrated via drug substrates, cited to Felmlee); NEW GO:0042910 xenobiotic transmembrane transporter activity for the drug-transport specificity; bare GO:0005515 protein-binding REMOVE (x2); GO:0016323 basolateral IBA MARK_AS_OVER_ANNOTATED (not grounded for MCT6); GO:0055085 KEEP_AS_NON_CORE (no GO:1905039 row to anchor TOO_GENERAL).
