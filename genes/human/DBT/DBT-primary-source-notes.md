# DBT primary-source assay notes

These are authored summaries of selected original evidence, not alterations to the publication caches.

## Human E2 lipoyl-domain construct

[PMID:11839747](https://doi.org/10.1074/jbc.M110952200), Sample Preparation and Results, describes a 93-residue recombinant NMR construct containing native lipoyl-domain residues 1–84, an additional N-terminal methionine and a C-terminal LE/His tag. The [1K8M polymer entity](https://data.rcsb.org/rest/v1/core/polymer_entity/1K8M/1) maps the native 84-residue sequence exactly to P11182 residues 62–145. Thus paper Gly1 corresponds to precursor Gly62, and lipoyl Lys44 corresponds to Lys105. Selected author-original text was read; figure pixels and the entire paper were not independently assessed. This structure does not measure full-length E2 catalytic turnover.

[PMID:7918575](https://doi.org/10.1016/0304-4165(94)90161-9), complete abstract, explicitly reports microsequencing human E2 and an N-terminal glycine. The full original remained inaccessible. The current UniProt reference-position field 47–81 is inconsistent with current Tyr47; the discrepancy is not resolved by relabeling an old coordinate system. The official 62–482 mature chain remains prediction-based.

[PMID:37558654](https://doi.org/10.1038/s41467-023-40536-y), Methods, Protein-protein interaction AlphaLISA assay, specifies human DBT residues 62–482 with N-terminal FLAG/TEV for bacterial expression. Results and Figure 8C report compound-dependent changes in BDK–E2 proximity. This is a tested recombinant construct, separately from the mouse-heart co-immunoprecipitation experiment. It is not direct endogenous processing evidence or an isolated E2 kinetic assay.

## Nucleoid association

[PMID:18063578](https://pubmed.ncbi.nlm.nih.gov/18063578/), original Table 1, places BCKD E2 / DBT / NP_001909 in Class I. The two native-preparation peptide counts are 0 and 3; the two cross-linked-preparation counts are 12 and 2. Original Methods describe native and formaldehyde-cross-linked nucleoid preparations, and the Discussion limits inference from these associations. These target-specific cells overturn the earlier claim that DBT appeared only as a native-preparation contaminant. Cross-linked association does not by itself establish direct DNA contact or a functional DNA-maintenance role. The standard cache remains abstract-only; this table assessment uses the separately recovered author original.

## Human mitochondrial proteome

[PMID:34800366](https://doi.org/10.1016/j.cmet.2021.11.001), Table S1, contains P11182/DBT protein group 3886 in sheet A row 292 and sheet B row 265. Sheet A records subtractive Class 1, spatial Cluster 1 and importomics Class 1. Its membrane-association field is Peripheral. STAR Methods describe carbonate extraction and sonication of purified HEK mitochondria, pellet/supernatant ratios and operational clustering. This is compatible with a matrix enzyme associated with a complex; it does not localize a membrane face or prove an exclusively freely soluble pool. The matrix GO column is prior annotation rather than an independent submitochondrial measurement. The evidence guide retains the small target-cell projection and exact header labels without recoding missing values.
