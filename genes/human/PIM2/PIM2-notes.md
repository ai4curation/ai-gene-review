# PIM2 curation notes

Deep research providers were unavailable in this worktree: Falcon and Perplexity failed before creating provider files, so this review uses the fetched GOA, UniProt, PAINT, PMID caches and manual inspection.

The core PIM2 function is protein serine/threonine kinase activity driving cell-survival and substrate-stabilization outputs. PMID:20307683 gives direct support for p21 phosphorylation and stabilization. BAD-mediated apoptosis support comes from PMID:18675992. The EV71 response row from PMID:16548883 remains undecided because the cached abstract describes a global expression screen and does not expose the PIM2-specific measurement.
