# APOO / MIC26 bioinformatics

Sequence-level test of whether the APOO/MIC26 N-terminus is a secretory signal peptide or a
mitochondrial targeting presequence, plus a MIC26-vs-MIC27 architecture comparison.

```bash
uv run python targeting_sequence_analysis.py
```

Findings and caveats: [RESULTS.md](RESULTS.md). Raw numbers: `results.json`.
