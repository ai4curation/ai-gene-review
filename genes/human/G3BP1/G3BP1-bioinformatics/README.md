# G3BP1 bioinformatics

One analysis, testing the ATP-dependent helicase annotations on human G3BP1
(Q13283) against the protein's own sequence and domain architecture.

- `reproduce.py` — two parts, both writing to `results.json`:
  1. fetches UniProtKB records for G3BP1 plus four positive controls (DDX3X,
     EIF4A3, BLM, UPF1) and two fold-matched negative controls (NUTF2, HNRNPA1)
     from the UniProt REST API, scans each for canonical helicase/ATPase motifs,
     and checks each entry's domain signatures for a helicase or RecA/AAA/P-loop
     ATPase core;
  2. queries QuickGO for every reviewed member of PANTHER family PTHR10693 and
     records which helicase terms each carries and under which evidence codes, to
     see what descendant evidence the helicase IBA's node actually rests on.
     Needs `interpro/panther/PTHR10693/PTHR10693-entries.csv` (written by
     `just fetch-gene human G3BP1`); skipped with a printed notice if absent.
- `RESULTS.md` — question, method, results tables and interpretation.
- `results.json` — computed output (regenerated by the script, not hand-edited).
- `cache/` — cached UniProt and QuickGO JSON responses (git-ignored; the script re-fetches if absent).

No API key or authentication is needed. Run:

```bash
python3 reproduce.py
```

The script has no third-party dependencies (standard library only), so `uv` is
optional; `uv run reproduce.py` also works.
