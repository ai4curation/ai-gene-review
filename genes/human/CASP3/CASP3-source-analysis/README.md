# CASP3/Casp3 source evidence audit for PR5558

The audit now covers 75 rows: 31 human CASP3 and 44 mouse Casp3. This comprises the original 37 rows and 38 additional residual-uncertainty rows (6 human, 32 mouse), including every remaining UNDECIDED claim in these two reviews. It traces source experiments rather than inferring functions from annotation counts.

- `transfer-evidence-audit.yaml` is the authored assessment authority, as required by CLAUDE.md for authored structured data. It records each claim, donor provenance, primary PMIDs, final action and source-specific rationale.
- `transfer-evidence-audit.tsv` is now a deterministic export of that YAML, retained for compatibility and comparison with the original audit. It is not separately hand-edited.
- `trace_donors.py` regenerates the TSV, source-access hashes, donor traces, cross-species tuple checks and live annotation provenance. It checks that audited term/action/rationale match the actual reviews. It does not make biological decisions.
- `donor-trace.json` reads only GO TERM, REFERENCE, GO EVIDENCE CODE and WITH/FROM from the normally fetched seed TSVs. Relationship qualifiers are neither exported nor interpreted. Legacy human rows lack supporting_entities, so consulting the normal TSV is needed solely to recover donor provenance.
- `cross-species-tuples.json` verifies paired term/evidence/reference/donor tuples. The residual round includes 16 exact rat-donor IEA matches to already resolved human rows and 2 rat ISO rows with the same donor protein represented as RGD:2275.
- `rat-annotation-provenance.json` and `human-annotation-provenance.json` are filtered live QuickGO outputs used to find original references. Human provenance uses exact GO:0035655/0043066/0072734. Missing current source annotations are not evidence that a function is false. These files are annotation state, never functional support cited by a review.
- `publication-access.json` identifies all inspected primary caches used by these 75 assessments, their actual local full-text status and SHA256 hashes.
- `go-definitions.json`, `additional-go-definitions.json` and `cobalt-response-ancestry.json` record the exact official definitions/ancestry used to distinguish response terms, binding and complex membership, IL-18 receptor signaling versus cytokine processing, developmental anatomy, and the supported cobalt refinement.

Run `uv run python genes/human/CASP3/CASP3-source-analysis/trace_donors.py` from the repository root to reproduce the derived files. Live annotation provenance can change. The authored YAML fixes the scope and biological assessment. This folder deliberately holds source/provenance analysis rather than custom sequence or structural bioinformatics, so its established name is retained.

The expanded 75 outcomes are 46 KEEP_AS_NON_CORE, 2 MODIFY, 2 MARK_AS_OVER_ANNOTATED and 25 UNDECIDED. The two over-annotation judgments concern human and mouse swimming-behavior transfers from the same rat IGF1 cognitive study that measures CASP3 as a marker. They do not deny neuronal CASP3 activity.

The residual audit removes every generic CC:FUNCTION quote from uncertain claims. Most matching stimulus responses can be retained on the same primary evidence as the human rows; glucose and nicotine retain their specific unavailable-assay limits. Native mouse full PMID:16469926 directly resolves UV/staurosporine experiments and avoids treating non-necessity in one neural precursor model as absence of all response activity. Full PMID:22949508 establishes a real protective Casp3/RasGAP/Akt mechanism in stressed mice. The IL-18 receptor-signaling assertion remains unresolved because the recovered human source demonstrates ligand cleavage/inactivation rather than an identified receptor-signaling step. Three distinct binding classes remain uncertain because abstract-only PMID:17518537 exposes DISC association but not the precise pair-versus-complex assay needed to distinguish them. No wrong-gene claim is inferred from an abstract's focus or omission.
