# EGFR portable source evidence

This bundle makes three source-derived checks reproducible with Python 3.9 or later and no third-party packages:

```sh
python3 reproduce.py
```

The script verifies every input hash before parsing. It decompresses the exact 1,942-record IntAct export, joins the 603 IPI source assertions by PMID and literal target/partner identities, and reproduces the 726 selected records. The compact output retains method, taxa, record identifiers, features, negative flags and sequence checksums. A missing match is not negative interaction evidence; this export is one dated database snapshot. The biological decisions also use the source-specific original assays and partner classification recorded in the review.

The same script parses the authentic supplementary Data 8 workbook from PMID:37100772 using standard-library XML/ZIP support. It selects the EGFR peptide by its accession rather than a hardcoded row number or affinity. Finally it reconstructs all full GOA contexts, including relation, support set, polarity and isoform. It verifies the 48 historical lifecycle flags and exact coverage of all 958 current contexts, keeping the two inherited NEW rows separate.

`inputs.json` provides download URLs and hashes. The IntAct export is compressed without changing its decompressed bytes. The 20-KiB peptide workbook is included unchanged. The canonical current GOA is one directory above this bundle; the original GOA is preserved under `archive/`. Full scientific article bodies are not bundled.

To write fresh derived outputs to a separate directory:

```sh
python3 reproduce.py --output /tmp/egfr-replay
```

The default invocation compares freshly computed objects to `outputs/`. The script makes no network requests and makes no curation decisions. It will reject substituted input versions rather than silently recomputing against changed database data.

`reactome-source-chains.json` and `paint-tree-proof.json` are separate inspectable database provenance, not outputs claimed to be regenerated by this script. They retain selected event edges, target identity, ancestral placement and scope limits. The Reactome traversal sought target witnesses and left 64 unrelated branches unexpanded; it is not an exhaustive pathway closure. The publication cache inventory and source-specific reference assessments are in `../EGFR-source-evidence.yaml`.
