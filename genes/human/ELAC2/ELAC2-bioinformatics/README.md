# ELAC2 database evidence replay

Run `python3 reproduce.py` from any directory with Python 3.9 or later. No packages, network calls, repository checkout or publication bodies are required. A successful run prints a compact JSON result. It authenticates the archive, every member, the original extraction scripts, retrieval provenance and saved expected projection before reconstructing the data in a temporary directory. It also reconstructs all four official splice-product sequences and compares them with the saved official FASTAs.

`source-inputs.zip` contains unchanged official database bytes: PAINT tree/MSA and the complete saved IBD file; QuickGO target/donor records and term definitions with typed ancestry; UniProt target/donor records; Reactome target catalyst chains; InterPro matches, ARBA conditions, EC mapping and subcellular-location mappings; HPA localization metadata; and official product FASTAs. The source dictionaries are the 36 preserved annotation assertions, with their original qualifiers and product context. No annotation judgments are generated by this script. One saved 404 response from the unused enzyme endpoint is retained as a failed acquisition, not interpreted as enzyme evidence; the successful ec2go mapping supplies the EC provenance.

`replay_database.py` and `reconstruct_paint.py` are unchanged extraction code from the independent source review. `expected-results.json` is their saved complete output. `inputs.json` pins every byte used. `retrieval-provenance.json` records the original source URLs, retrieval times, HTTP statuses and data hashes. Transport headers and server cookies are omitted from this public provenance projection; original receipts remain immutable in the evidence archive. The `private-evidence:` labels identify those archived origins and are not runtime paths or dependencies.

The raw-input hash predicate is also exercised on deliberately changed in-memory bytes and must reject them. An actual reconstruction mismatch fails the command. This is a finite source-evidence replay, not a gene validator, status computation, rendering check or test of an experimentally unmeasured splice product.

See [RESULTS.md](RESULTS.md) for the biological interpretation and [the source guide](../ELAC2-source-evidence.yaml) for original-paper access limits.
