# PMS2 PTHR10073 review notes

PMS2 was reviewed as the catalytic human MutLalpha endonuclease subunit. The row set separates PMS2 core functions from generic protein-binding rows, secondary DNA-binding rows, and a ComplexPortal meiotic mismatch-repair term that cites a somatic MutLalpha reconstitution paper.

Key papers checked locally: PMID:16873062 localizes the human MutLalpha endonuclease site to PMS2; PMID:11574484 and PMID:30653781 support ATP hydrolysis by human PMS2 N-terminal constructs; PMID:10871409 supports a PMS2-dependent MMR cellular phenotype but not direct DNA binding; PMID:33510387 assays MLH1-PMS2, which corroborates that the GO Central PMS1 endonuclease row from the same PMID most likely targeted the yeast Pms1 name to the human PMS1 gene instead of human PMS2.
