# Primary check of PMID:21121900

Inspected the [author-deposited full text](https://www.researchgate.net/publication/49649174_The_phosphoinositide_3-kinase_Vps34p_is_required_for_pexophagy_in_Saccharomyces_cerevisiae), Grunau et al., Biochemical Journal 434:161–170, DOI 10.1042/BJ20101115, on 2026-09-20. This manual note supplements the abstract-only publication cache.

Figures 1–2 examine oleate-induced yeast peroxisomes by organelle purification, phosphoinositide synthesis and protein fractionation; Vps34 cofractionates with peroxisomal markers. The Results state: “a significant portion of Vps34 is associated with peroxisomes.” These experiments concern peroxisome biogenesis conditions, not solely an engulfing autophagic membrane.

Figure 4B tests separate VPS15, VPS30, ATG14 and VPS38 deletions. Loss of the first three blocks peroxisomal thiolase degradation; VPS38 deletion does not. This distinguishes the complex-I execution machinery from complex II. It supports conserved VPS15/VPS34 complex participation, while neither proving human peroxisomal localization nor requiring each execution factor to recognize cargo.
