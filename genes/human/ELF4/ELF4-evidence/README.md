# ELF4 official database evidence

Run `python3 reproduce.py` from this directory, or pass its full path. Python's standard library is sufficient. No network, installation or repository environment is required. Keep the script, `config.json`, `inputs.json`, `database-inputs.zip` and `results.json` together. The command verifies every input and compares a new projection with the saved result. `--write NEW.json` instead creates a new result file exclusively; it will not overwrite an existing file.

The archive contains 46 authentic database/API and machine-source inputs: UniProt, normal GOA, official QuickGO records, PANTHER tree/MSA, the fixed PAINT IBD snapshot, ARBA rules, InterPro mappings, UniProt location vocabulary and HPA XML. It contains no original article bodies, figure files, provider logs or annotation decisions. The complete IBD snapshot is included so the target-path selection can be recomputed. `inputs.json` records exact hashes, sizes and acquisition URLs where available. All reads are from the archive without filesystem extraction.

The program rejects missing or changed inputs, extra or duplicate archive members, unsafe paths, symbolic links, encrypted members and unexpected sizes. Its checks remain active under `python -O`. It calculates source-context multiplicity, target sequence agreement, IBD ancestry and donor-list differences, selected rule premises, donor records, typed ontology ancestry and HPA locations. It does not reproduce assays, determine biological actions, infer absent functions from missing records, or claim exhaustive ARBA firing. `original-locators.json` separately records public article routes and the actual bounded original reading; those unbundled inputs are not required for database replay.
