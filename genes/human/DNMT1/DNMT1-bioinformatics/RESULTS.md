# DNMT1 source-extract results

The genuine MitoCoP workbook contains three selected rows: sheet A, Excel rows 324 and 3558, and sheet B, Excel row 294. The first group (4315) includes P26358, P26358-3 and additional accession records; it is a MitoCoP component in pool 3, with importomics classification Class 1. Its mean log2 TOMM40-knockdown/mock value is -1.18000978898823, with four valid ratios and 15.85% sequence coverage. The workbook's literal statistic header is `-log2 p-value`, with value 8.05229321515582. Spatial proteomics instead places the group in Cluster 2, and subtractive ratios are unavailable. The separate group 4316 includes P26358-2 and is not selected as a MitoCoP component. These are protein-group observations, not isoform-resolved proof. They support a contextual mitochondrial pool; neither mitochondrial DNA methylation nor a submitochondrial compartment is measured by this extract. See the [original study](https://doi.org/10.1016/j.cmet.2021.11.001) and its source data.

The OpenCell data contain one DNMT1 record: CSV line 29629 (zero-based data index 29627), YWHAZ bait and DNMT1 prey. The exact prey accession group is `P26358;P26358-2;P26358-3;K7EP77;K7EMU8;K7EJL0`. The original columns report enrichment 2.69151466870597, `pval` 22.0693662356999, interaction stoichiometry 0.000150294351115587 and abundance stoichiometry 0.0300492869528021. These values are copied without relabeling the source statistic. This is a positive endogenous-tag affinity-capture association, not a purified pair-binding measurement or an assignment to one DNMT1 product. See the [original study](https://doi.org/10.1126/science.abi6983) and [downloadable CSV](https://opencell.czbiohub.org/data/datasets/opencell-protein-interactions.csv).

The standard-library extractor was replayed against the saved raw sources and matched the independently inspected workbook rows and CSV record exactly. A separate DNAJC19 selection produced two workbook rows and no OpenCell records, confirming that target counts are computed rather than embedded in the script.
