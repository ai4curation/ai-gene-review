## What the one characterised relative does

The family is not entirely uncharacterised. 7 of its 13
reviewed members carry a UniProt FUNCTION statement about mitochondrial
complex I assembly, and all of them are **NDUFAF3** entries. That branch is an
**assembly factor for mitochondrial complex I**, consistently across every
organism in which it has been studied; the Drosophila entry cites experimental
evidence (PubMed:34386730).

This is informative in a specific way. NDUFAF3 is an **assembly factor, not an
enzyme**: it has no catalytic activity, it binds subunits and helps build a complex,
and it is not part of the finished complex. Consistent with that, no member of this
family - including NDUFAF3 itself - carries a CATALYTIC ACTIVITY block or an
experimental molecular function term.

So the family signal does *not* point toward a hidden enzymatic activity waiting to
be found for AAMDC. It points toward a protein-assembly / chaperone-like role, which
is a class of function GO struggles to express as a molecular function in any case
(there is no assembly-chaperone MF term; see the AAGAB review in this campaign).
That makes the AAMDC review's refusal to assign an MF the right call, and it also
suggests where to look experimentally: what complex, if any, does AAMDC help
assemble?
