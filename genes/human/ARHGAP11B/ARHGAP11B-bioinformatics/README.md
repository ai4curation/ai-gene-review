# ARHGAP11B bioinformatics

## Question

Human ARHGAP11B carries two curated `NOT enables GO:0005096 GTPase activator activity`
IDA annotations, yet Reactome asserts the positive `enables GO:0005096` by TAS and
InterPro's RhoGAP-domain signature supplies `GO:0007165` by IEA. The campaign's usual
way of adjudicating a claimed-inactive enzyme is to ask whether the catalytic residues
are still there.

This directory asks that question properly, expecting it to *fail*, and measures what
the truncation actually removes instead.

## Run

```
uv run --no-project --with "biopython>=1.85" python analyze_arhgap11b.py
uv run --no-project --with "biopython>=1.85" python analyze_arhgap11b.py --self-test
```

Everything is fetched live from UniProt, PDB and the PROSITE cross-reference index and
cached under `cache/` (git-ignored). There is no offline fallback and no hardcoded
result: a missing input is a hard error naming the fix, never a silently dropped
section. `RESULTS.md` and `results.json` are regenerated by a run and reproduce exactly.

## `check_review_counts.py`

```
uv run python check_review_counts.py
uv run python check_review_counts.py --self-test
```

Reconciles `existing_annotations` against the GOA TSV row count, tallies the actions,
rejects duplicate YAML keys with a strict loader, and asserts that no experimental
annotation was removed or demoted and that every REMOVE/MARK on a propagated evidence code
carries a `propagation_review`.

It earned its keep on its first run. The hand tally in the notes, the PR body and the commit
message said **ACCEPT 12** and wrote the arithmetic as `12 + 2 + 4 = 18` — which *also* came
to 18, because it had dropped the NEW row from the sum at the same moment as inflating
ACCEPT by one. Two errors cancelling into a total that looked reconciled. The true tally is
**ACCEPT 11, MODIFY 2, REMOVE 4, NEW 1**, and the row list printed beside the wrong number
had been correct all along.

## What it measures

1. **Divergence point.** ARHGAP11B vs ARHGAP11A, scored positionally after *proving*
   colinearity. The boundary is a changepoint fitted to the per-residue identity vector
   with its significance set by permutation, so no identity cutoff is chosen anywhere.
2. **Arginine finger.** Each control's own annotated arginine finger is aligned onto
   ARHGAP11B and scored as retained only if the residue is an arginine **and** the
   aligned position lands on one of ARHGAP11B's own annotated Site features.
3. **Does that test discriminate?** The same question is asked of every reviewed human
   protein carrying the PROSITE RhoGAP profile, so "the catalytic residue is present"
   can be weighed rather than asserted.
4. **What the truncation removes.** The GAP:GTPase interface from a transition-state
   crystal structure, projected onto ARHGAP11A and split at the divergence point.
5. **The UniProt domain boundary** on ARHGAP11B versus that divergence point.

## Guards, and the two bugs they caught

Both of these produced confident, plausible, wrong numbers before being caught. They
are described here because the guard is only meaningful if you know what it is for.

- **Out-of-register projection.** ARHGAP1 carries its Rho-GAP domain at the C-terminus
  behind a CRAL-TRIO domain; ARHGAP11A carries its at the N-terminus of a 1023-residue
  protein. A global alignment of the two full sequences pairs N-terminus with
  N-terminus and put the arginine finger on ARHGAP11A residue **684**. The fix is a
  reciprocal anchor: the projection is rejected unless the control's arginine finger
  lands on the paralog's *own annotated* arginine finger.
- **Alignment-limited, not biology-limited.** With that fixed, a local alignment
  reported **0 of 25** interface contacts lost — but it had stopped at control residue
  401 / ARHGAP11A residue 204, i.e. just short of the divergence point at 220. Six
  contacts lay past its end: not absent, *not measured*. The fix runs a second
  domain-to-domain global projection that cannot truncate, and accepts it only if it
  agrees with the local one at every position both cover. The honest answer is **2 of
  24**, not 0 of 25.

`--self-test` breaks six things on purpose and requires each check to notice: removing
the arginine finger, restoring the paralog C-terminus, swapping the structure's chain
roles, a census that cannot see a lost arginine, an empty UniProt record, and an
out-of-register projection. Each mutation asserts its anchor is present before mutating,
so a drifted target is an error rather than a vacuous pass. A passing self-test only
proves the guards that were written fire; it says nothing about the guard that was not.
