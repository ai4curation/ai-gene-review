# gyrB source and preservation proof

`pristine-seed.yaml` is the untouched initial review plus original non-review annotation payloads and raw source hashes captured immediately after normal fetch. `identity-proof.yaml` records primary construct identities, strain, tags, sequence length/hash and source hashes. It explicitly distinguishes reported insert sequencing from independent plasmid-sequence reconstruction.

The 2006 H37Rv study (PMID17038336) directly measures wild-type kDNA decatenation with both subunits. The 2025 study (PMID41255390) explicitly names current accessions but does not measure decatenation. No full PDFs/XML are redistributed here.
