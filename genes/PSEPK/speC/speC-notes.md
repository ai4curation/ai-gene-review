# speC curation notes

- Q88PI6 is an unreviewed, PE-3 ornithine decarboxylase candidate with exact EC
  4.1.1.17/RHEA:22964 chemistry, PLP cofactor, and PTHR11482:SF6 assignment.
  [file:PSEPK/speC/speC-uniprot.txt, "Reaction=L-ornithine + H(+) = putrescine
  + CO2", "PTHR11482:SF6; ORNITHINE DECARBOXYLASE 1-RELATED"]
- Pseudomonas genetics supports SpeC as an alternative direct route. In PAO1,
  loss of both SpeA and SpeC caused putrescine auxotrophy; in P. chlororaphis,
  loss of SpeC reduced polyamine production and the double mutant eliminated it.
  [PMID:12634339, "A mutant defective in both speA and speC was a putrescine
  auxotroph."] [PMID:28862813, "Polyamine production was reduced in the speC
  mutant, and was eliminated in the speAspeC mutant."]
- The completed OpenScientist module+ppu00330+PSEPK report identifies PP_0864 as
  the sole K01581 ortholog but found no KT2440 functional study. Separate
  gene-level and generic-module report files did not materialize.
  [file:projects/P_PUTIDA/deep-research/PSEPK__bacterial_putrescine_biosynthesis__ppu00330-deep-research-openscientist.md]

Residual uncertainty: native expression, route dominance, and redundancy with
SpeA-SpeB remain untested in KT2440.
