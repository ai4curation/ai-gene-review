# PP_3602 curation notes

- Q88GW5 is predicted to oxidize 2,5-dioxopentanoate to 2-oxoglutarate with
  either NAD+ (Rhea 47152) or NADP+ (Rhea 11296)
  [file:PSEPK/PP_3602/PP_3602-uniprot.txt, "Reaction=2,5-dioxopentanoate + NADP(+) + H2O = 2-oxoglutarate + NADPH +"].
- GO:0047533 names the NADP+-dependent form and is accepted. GO:0016620 is kept
  as non-core because it is the only current annotation that also covers the
  explicitly predicted NAD+-dependent reaction; only the root oxidoreductase
  term is treated as over-annotated.
- The locus context with PP_3599 and garD supports the aldarate-catabolism role,
  while the same enzyme family can also terminate other
  2,5-dioxopentanoate-producing routes.
