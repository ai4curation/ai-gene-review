# recO curation notes

## 2026-08-08 pathway pass

The target HAMAP record places Q88MY3 in the RecO family and RecF-pathway
recombination [file:PSEPK/recO/recO-uniprot.txt, "Involved in DNA repair and RecF
pathway recombination."]. Direct D. radiodurans homolog experiments show that
RecO binds exposed ssDNA, displaces SSB without ATP, and facilitates RecA loading
[PMID:32297860, "efficiently displaces drSSB from ssDNA without consuming ATP."].

Because GOA lacks a RecO molecular-function annotation, GO:0003697 is added as a
NEW ISS proposal using reviewed E. coli RecO UniProtKB:P0A7H3 plus the homolog
experiment. The same evidence supports the RecO leaf function in the module.
