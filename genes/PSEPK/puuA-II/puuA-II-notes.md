# puuA-II (Q88C84, PP_5299) curation notes

Provider deep research was not run for this gene in this session (no provider
credentials available). Sources: UniProt record, PTHR43785 PAINT table and
family review, PMID:18495664 (E. coli PuuA), PMID:21622750 (P. aeruginosa PauA
paralogs) and the KT2440 module research file.

- PANTHER PTHR43785:SF12, the mixed GS / gamma-glutamyl-amine ligase subfamily.
- The TreeGrafter polyamine catabolic process row can only come from
  PTN001839150, the PuuA/PauA clade (the sole PTHR43785 node carrying
  GO:0006598), so the protein is grafted inside the PuuA lineage rather than
  among the glutamine synthetases.
- Gene context: beside PP_5298, a PuuD-family hydrolase.
- Pseudomonas PauA paralogs have diversified polyamine specificities
  [PMID:21622750], so putrescine preference of this paralog is inferred, not
  shown.
