# astE curation notes

- Q88EI7 is assigned the exact zinc-dependent EC 3.5.1.96/RHEA:15169
  desuccinylation reaction [file:PSEPK/astE/astE-uniprot.txt
  "Reaction=N-succinyl-L-glutamate + H2O = L-glutamate + succinate;"].
- The exact amide-cleaving activity and L-arginine catabolic process are core.
  Zinc binding and the broad linear-amide hydrolase parent are non-core, while
  ester-bond hydrolase activity is chemically incorrect for this reaction.
- GOA PTN002309601 supports only the broad amide-hydrolase annotation; it is not
  used as an ancestral node for exact AstE substrate specificity.
