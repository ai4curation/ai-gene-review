# PP_3598 curation notes

Provider deep research was not run for this gene in this session (no provider
credentials available). The review uses the UniProt record, the PTHR43235 PAINT
table, cached E. coli PuuD and P. aeruginosa SpuA literature (PMID:15590624,
PMID:16499623, PMID:34605433, PMID:12081945) and the KT2440 module research
file (projects/P_PUTIDA/deep-research/PSEPK__gamma-glutamyl-putrescine-catabolism__ppu00330-deep-research-openscientist.md).

- PuuD-like InterPro signature (IPR044668) and PANTHER PTHR43235:SF1; the
  TreeGrafter rows descend from PAINT node PTN000230196, seeded by E. coli PuuD.
- P. aeruginosa SpuA "exhibits a preference for γ-Glu-GABA as a substrate"
  [PMID:34605433].
- The UniRule L-glutamine metabolic process row is marked over-annotated: it
  rests on the class I GATase fold, and the characterized ortholog SpuA prefers
  gamma-Glu-GABA [PMID:34605433], but this paralog is unassayed, so glutamine use
  is not excluded (same treatment as the GS rows on the KT2440 PuuA paralogs).
- KT2440 has three PuuD-family paralogs (PP_5298, PP_2179 spuA, PP_3598); none
  has been assayed.
