# kguE evidence notes

The requested OpenScientist run finished without leaving a final gene report, so this
manual note records the evidence used for curation. Cross-species knockout and
complementation show that KguE participates in 2KGA utilization, but the same paper
states, "However, the reaction KguE exactly catalyzes remains to be studied"
[PMID:39770733]. The EC 1.1.1.43-derived GO:0008114 annotation is therefore removed;
PP_3376/KguD occupies the terminal reductase position in the ordered pathway.
