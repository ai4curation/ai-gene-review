# PP_3599 curation notes

- Q88GW8 is a reviewed HAMAP entry for 5-dehydro-4-deoxyglucarate dehydratase,
  EC 4.2.1.41, Rhea 24608
  [file:PSEPK/PP_3599/PP_3599-uniprot.txt, "RecName: Full=5-dehydro-4-deoxyglucarate dehydratase"].
- The TreeGrafter 4-hydroxy-tetrahydrodipicolinate synthase annotation is a
  paralog transfer within the DapA-like TIM-barrel superfamily. The exact
  IPR017655/TIGR03249/NF002958 substrate-specific assignments resolve Q88GW8 as
  KDGDH, so the DapA activity is removed.
- The reaction is shared after the glucarate and galactarate entry branches;
  UniPathway currently names only the D-glucarate branch.
