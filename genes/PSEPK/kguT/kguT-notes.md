# kguT evidence notes

The requested OpenScientist run finished without leaving a final gene report, so this
manual note records the evidence used for curation. Q88HI0 is a 12-pass MFS protein in
the conserved kgu locus. Cross-species pathway evidence states that "2KGA in the
periplasmic space is transported into the cell by the 2KGA transporter KguT"
[PMID:39770733]. The substrate assignment is retained in prose because GO currently
provides only the broad transmembrane transporter molecular-function term.
