# FlyBase gene description for rl (DROME)

rolled (rl) encodes the mitogen activated protein (MAP) kinase, core component of the RAS/MAPK pathway. It is inactivated by the phosphatases encoded by PTP-ER and Mkp3. It phosphorylates a diverse set of downstream cytoplasmic and nuclear effectors, which impact cell fate decisions in a wide array of tissues.
