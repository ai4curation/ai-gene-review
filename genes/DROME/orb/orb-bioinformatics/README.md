# Orb isoform comparison

Run `just analyze` with pinned Biopython. The exact frozen Q8IMZ2 sequence is compared globally with long Orb Q9VCN7, downloaded from https://rest.uniprot.org/uniprotkb/Q9VCN7.json on 2026-09-09 UTC. Both records identify orb; no Orb2 sequence is used. The arbitrary-input script reports full alignment, sequence hash and indels. A distinct-gene positive control compares CG4793 Q8IP30 and RefSeq NP_723941.2 and recovers 910/910 identities.
