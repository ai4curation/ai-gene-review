# pmi40 (S. pombe, SPBC2G2.16, UniProt O43014) notes

## Identity
- UniProt O43014 (MPI_SCHPO), 412 aa, type I PMI family (PANTHER PTHR10309:SF0). UniProt gives the name pmi40, but its PomBase cross-reference carries no gene name ("PomBase; SPBC2G2.16; -."); GOA uses pmi40. Name inherited from S. cerevisiae PMI40.

## Function
- Mannose-6-phosphate isomerase, EC 5.3.1.8 [UniProt:O43014 "Reaction=D-mannose 6-phosphate = D-fructose 6-phosphate;"]; zinc cofactor (by similarity).
- UniProt pathway: GDP-mannose biosynthesis step 1/2.
- No S. pombe-specific biochemical or genetic paper among the GOA references; annotations are IBA/IEA/HDA only. Function relies on the type I PMI family and S. cerevisiae PMI40 [PMID:1377774 "Inactivation of PMI at the restrictive temperature of 37 degrees C prevents synthesis of the GDP-mannose and dolichol-phosphate-mannose required for a number of critical mannosyl transfer reactions and results in cell death."].

## Location
- Cytoplasm and nucleus in the ORFeome screen [PMID:16823372]; UniProt SUBCELLULAR LOCATION derived from that screen.

## Comparison with S. cerevisiae PMI40
- Same core MF/BP/location (GO:0004476, GO:0009298, cytosol). The S. cerevisiae review also lists a catabolic core function (GO:0019309 mannose catabolic process); S. pombe has no such annotation and I did not find S. pombe data for it, so it is not a core function here.

## GO-CAM
- pmi40 is in neither PomBase model linked to the modules (663d668500002302 glycolysis; 671ae02600003596 Dol-P-Man). Only SGD models (PWY3O-123, PWY3O-1743) contain PMI40.
