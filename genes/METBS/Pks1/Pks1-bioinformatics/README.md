# Pks1 Bioinformatics Audit

The generated PKS1 reports in this directory are retained as stale analysis
artifacts, not as curated evidence for `Pks1-ai-review.yaml`.

The 2026-10-10 audit found that the generated JSON contradicts the prose summaries
for several catalytic-residue checks, that the homolog identity values are
hand-entered rather than recomputed, and that the GO recommendations include
process terms that were rejected or narrowed in the 2026-10-01 re-review.

Use the cached UniProt record and PMID:29958281 for curated support.
