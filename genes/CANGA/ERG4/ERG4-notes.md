# ERG4 notes

C. glabrata ERG4 is in the SF31 fungal ERG4 branch of PTHR21257 and is predicted to catalyze the terminal Delta24(24-1) sterol reduction. PMID:36108742 tests late ergosterol genes, including CgERG4, in antifungal susceptibility; that supports the CGD xenobiotic-response phenotype but does not change the core assignment from the ERG4 C-24(28) reductase reaction.
