# NS1 binds C1QA
**Reactome ID:** [R-HSA-9920638](https://reactome.org/content/detail/R-HSA-9920638)
**Species:** Homo sapiens

## Summary

DENV-2 secreted NS1 protein can directly bind the complement protein C1q. This interaction is independent of posttranslational modification. It is unknown whether this interaction modulates complement activation. The direct binding was validated using NS1 from DENV-2 strain 16681, following an initial screen that used the NS1 gene from the DENV-2 NG-C strain (Silva et al., 2013).
