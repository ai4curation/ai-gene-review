# C binds DDX3X
**Reactome ID:** [R-HSA-9921600](https://reactome.org/content/detail/R-HSA-9921600)
**Species:** Homo sapiens

## Summary

DENV capsid (C) protein interacts with ATP-dependent RNA helicase DDX3X. Silencing DDX3X expression led to increased DENV titers. This suggests an apparent antiviral function of DDX3X. The result was obtained from experiments with the Dengue serotype-2 (DENV-2) P23085 strain (Kumar et al., 2018).
