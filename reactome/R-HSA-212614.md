# Glutamine transport from astrocytes
**Reactome ID:** [R-HSA-212614](https://reactome.org/content/detail/R-HSA-212614)
**Species:** Homo sapiens

## Summary

Glutamine from the astrocytes is exported to the extracellular compartment via the system N amino acid transporter. The system N transporter is Na+ dependant  transporter that has substrate specificity to aspargine, glutamine and histidine.
