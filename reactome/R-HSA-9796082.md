# AcK-NFE2L2 binds the EGF gene
**Reactome ID:** [R-HSA-9796082](https://reactome.org/content/detail/R-HSA-9796082)
**Species:** Homo sapiens

## Summary

ChIP-sequencing data show that  NFE2L2 directly binds to the promoter of EGF, which contains a canonical antioxidant response element (Kreb et al, 2021)
