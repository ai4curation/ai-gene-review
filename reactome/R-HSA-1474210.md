# Collagen type III degradation by MMP14
**Reactome ID:** [R-HSA-1474210](https://reactome.org/content/detail/R-HSA-1474210)
**Species:** Homo sapiens

## Summary

The membrane-type MMP MMP14 (MT1-MMP) is a fibrillar collagenase able to degrade collagen types I, II and III (Ohuchi et al. 1997).
