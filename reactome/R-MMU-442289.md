# Syk binds Vav2
**Reactome ID:** [R-MMU-442289](https://reactome.org/content/detail/R-MMU-442289)
**Species:** Mus musculus

## Summary

Constructs containing the C-terminal SH3-SH2-SH3 domain of Vav2 interact with Syk. An SH2-inactivating point mutation (R688Q) abolishes the interaction.
