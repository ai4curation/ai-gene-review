# CRPPA dimer transfers cytidylyl to Rbt5P
**Reactome ID:** [R-HSA-9940844](https://reactome.org/content/detail/R-HSA-9940844)
**Species:** Homo sapiens

## Summary

D-ribitol-5-phosphate cytidylyltransferase (CRPPA) homodimer transfers a cytidylyl moiety from CTP to D-ribitol 5-phosphate (Rbt5P), forming CDP-ribitol and diphosphate (Riemersma et al., 2015; Praissman et al., 2016). Mutations in CRPPA can cause forms of muscular dystrophy (MDDGA7, MIM:614643, Willer et al., 2012; MDDGC7, MIM:616052, Tasca et al., 2013). It is unclear which process provides the small amounts of Rbt5P needed for alpha-DAG1 glycosylation. It is possible that FGGY kinase, which has some activity against ribitol, plays this role so could provide Rbt5P (Singh et al., 2017).
