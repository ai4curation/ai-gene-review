# Collagen type X binds integrin alpha2beta1
**Reactome ID:** [R-NUL-2545201](https://reactome.org/content/detail/R-NUL-2545201)
**Species:** Homo sapiens

## Summary

The NC1 domain of collagen type X interacts with integrin alpha2beta1 (Chen et al. 1999). During endochondrial ossification Collagen type X is deposited in the hypertrophic zone of the growth plate. It interacts directly with chondrocytes via Integrin alpha2beta1 (Luckman et al. 2003).
