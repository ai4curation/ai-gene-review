Description

Assigns GO:1990858 cellular response to lectin through two alternative condition sets of CATH FunFams with a taxon: a pair of FunFams that together select group I p21-activated kinases (PAK1, PAK2, PAK3) in Primates, and a pair that selects CREBBP and EP300 in Catarrhini.

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: both live condition sets were examined. Set 1 matches five primate Swiss-Prot entries, all PAK1, PAK2 or PAK3; set 2 matches human CREBBP and EP300. The five human proteins are annotated by Reactome (TAS, R-HSA-5621481) to GO:0002223 (stimulatory C-type lectin receptor signaling pathway), a child of the rule's term, so the rule does not produce false statements among the proteins it selects, but there is no experimental GO evidence for the term on any of them. Meaning and parsimony: the two sets select unrelated families (group I p21-activated kinases; the CBP/p300 acetyltransferases) that share the consequent only through membership of one Reactome pathway, and GO:1990858 (cellular response to lectin) says nothing about what either does. The rule is also dead weight: ARBA00087826 asserts the more specific GO:0002223 (stimulatory C-type lectin receptor signaling pathway) with the same two condition sets, UniProt keeps only the most specific ARBA term, and QuickGO holds no annotation attributed to ARBA00089180 (0, against 323 for ARBA00087826).

Action Rationale

Every condition set of the rule is matched, signature for signature and taxon for taxon, by a rule asserting a descendant term, so the rule emits nothing and removing it changes no annotation. Replacing the consequent with the child term, as first proposed, would only duplicate ARBA00087826.

Biological Meaning

HETEROGENEOUS

Two unrelated units, kinases and acetyltransferases, both generic signalling components. The consequent fits them only through a pathway-membership annotation (Reactome TAS R-HSA-5621481 on the human proteins), not through an assay of a response to lectin. The term itself is narrow (1 descendant), so the problem is not generality but that the grouping is a pathway list.

The consequent term has 1 descendant terms. 2 condition set(s) are also matched by a rule asserting a more specific term. 2 condition set(s) were examined for this judgement.

Assessments

REDUNDANT

rule_redundancy.tsv: 2 condition sets, 2 covered by a rule asserting GO:0002223 (stimulatory C-type lectin receptor signaling pathway). The covering rule is ARBA00087826, whose two sets are identical to this rule's (rest.uniprot.org/arba search, 2026-11-12). QuickGO annotation search withFrom=ARBA:ARBA00089180 returns 0 annotations; withFrom=ARBA:ARBA00087826 returns 323. Within set 2 the two FunFams also match the same five Swiss-Prot entries, so one of them is unnecessary.

WEAK

The only manual support is a Reactome pathway-membership statement: Q13153 (PAK1), Q13177 (PAK2), O75914 (PAK3), Q92793 (CREBBP) and Q09472 (EP300) each carry GO:0002223, TAS, Reactome:R-HSA-5621481 (QuickGO, November 2026). No experimental annotation to GO:1990858 or a descendant exists on these proteins.

TOO_BROAD

The curated annotations on all matched human proteins are to GO:0002223 (stimulatory C-type lectin receptor signaling pathway), an is_a descendant of GO:1990858 (cellular response to lectin), and a separate rule already asserts that descendant for the same proteins.

TOO_NARROW

Primates for the PAK set and Catarrhini for the CBP/p300 set. Both families are found throughout animals; the restriction follows the source of the support (human Reactome TAS annotations), not the distribution of the proteins or the pathway. That is narrow coverage, not wrong annotation.
