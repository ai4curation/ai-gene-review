Description

Assigns GO:1903711 (spermidine transmembrane transport) to fungal proteins in CATH FunFam 1.20.1730.10:FF:000006 (Urea active transporter), the family of the DUR3 polyamine and urea transporter.

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: the live rule has one condition set, CATH FunFam 1.20.1730.10:FF:000006 (Urea active transporter) in Fungi. Its Swiss-Prot matches are S. cerevisiae DUR3 (P33413), C. albicans DUR3 (A0A1D8PDB5) and S. pombe dur3-1 (O94469). P33413 has GO:0015606 (spermidine transmembrane transporter activity) by IDA and IMP and A0A1D8PDB5 by IMP; GO:0015606 is part_of GO:1903711 (spermidine transmembrane transport), so the annotation is true of the characterised members. Meaning and parsimony: the set selects one unit, the fungal DUR3 urea and polyamine transporters, and the consequent is an informative statement about it. But the same set is covered by ARBA00089374, which asserts GO:0015606, the molecular function that implies this process by part_of. UniProt keeps the more specific ARBA term, and QuickGO holds no annotation with ARBA:ARBA00089391 as its source (2026-11-12), so the rule does no work.

Action Rationale

The rule is coherent and true, but its only condition set is covered by ARBA00089374 (GO:0015606, spermidine transmembrane transporter activity), from which the process term follows by part_of, and the rule produces no annotation. It should be retired as redundant. Confidence is moderate: the covering term is in the other aspect, so retiring the rule relies on GO inference from function to process, and the zero count is one QuickGO snapshot.
