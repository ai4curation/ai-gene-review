Description

ARBA rule assigning the pathway comment "Pyrimidine metabolism; UMP biosynthesis via de novo pathway" through 26 alternative condition sets built from InterPro, CATH FunFam, PANTHER and taxon conditions.

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: all 26 condition sets were turned into UniProtKB queries. In every set, every reviewed match carries the curated pathway comment for de novo UMP biosynthesis; no reviewed match lacks it. Meaning and parsimony: the sets resolve into the enzymes of one pathway (carbamoyl-phosphate synthase, aspartate carbamoyltransferase, dihydroorotase, dihydroorotate dehydrogenase with its electron-transfer subunit, orotate phosphoribosyltransferase and orotidine 5'-phosphate decarboxylase), and the pathway comment is the statement that is true of all of them, so the rule is a coherent biological statement. It is not minimal: nine FunFam sets match no protein that another set of the rule does not already match.

Action Rationale

The rule is accurate and coherent. The only defect is redundancy: sets 10, 11, 14, 16, 17, 18, 19, 23 and 26 add no protein in the current release, so they can be removed without changing what the rule annotates. If redundancy of this kind is tolerated as insurance against signature changes, the rule can stand as it is; nothing about its annotations needs correcting.

Assessments

REDUNDANT

Each signature is used in one set and no set is contained in another by its conditions, but by matched proteins nine of the 26 sets add nothing: UniProtKB queries for each set NOT (all other sets) return 0 for sets 10, 11, 14, 16, 17, 18, 19, 23 and 26 (1377, 1307, 1304, 2230, 3230, 1834, 315, 5 and 5922 entries). The other FunFam sets do add proteins (set 12: 666, set 21: 15442, set 22: 722, set 24: 554, set 25: 255). No single InterPro entry maps to this pathway comment, so the multi-set form itself is needed: six enzymes cannot share one signature.

APPROPRIATE

The pathway is universal. Eighteen sets carry no taxon condition; the eight that do (Eukaryota, Bacteria, Bacillati, Fungi, Pseudomonadati, Bacillota, Thermotogati, Archaea) confine a FunFam to the lineage where its reviewed members are, and every reviewed match inside them has the pathway comment.
