Review Summary

461 of the 4,603 live condition sets (every tenth set, starting with set 1) were screened with two UniProtKB queries each (2026-11-10): the Swiss-Prot entries that match the whole conjunction, and how many of them carry KW-0808 Transferase. Every screened set matches at least one Swiss-Prot entry. Summed over the screened sets there are 21,413 set-level matches (an entry that matches several sets is counted once per set) and 21,413 of them carry the keyword. No screened set has a Swiss-Prot match without the keyword. 10 sets are recorded in the rule block with official signature names; the other screened sets were checked by count only and their signatures were not read. 385 of the 4,603 sets have a taxon condition. ARBA rules are mined from Swiss-Prot annotation, so this screen shows that no screened set conflicts with curated keywords; it does not measure precision on the 12,487,598 unreviewed entries the rule annotates.

Action Rationale

The rule was not read set by set: 10 of 4,603 condition sets are recorded and 461 were screened by count. Nothing found argues against the rule. The keyword Transferase is defined by UniProt as: Enzyme that transfers a chemical group, e.g. a methyl group or a glycosyl group from one compound (donor) to another compound (acceptor). It is a class label, so diversity among its members is expected, and in every screened set all Swiss-Prot matches carry it. UniProt maps KW-0808 to GO:0016740 transferase activity. A verdict on the whole rule needs every set to be read and precision on unreviewed entries to be measured.
