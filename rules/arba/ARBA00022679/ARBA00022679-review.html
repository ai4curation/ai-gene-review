Description

Assigns the UniProt keyword KW-0808 (Transferase) through 4,603 alternative condition sets built from InterPro, PANTHER and CATH FunFam signatures.

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: 461 of the 4,603 live condition sets (every tenth set, starting with set 1) were screened with two UniProtKB queries each (2026-11-10): the Swiss-Prot entries that match the whole conjunction, and how many of them carry KW-0808 (Transferase). Every screened set matches at least one Swiss-Prot entry, and all 21,413 set-level matches carry the keyword. Ten sets are recorded with official signature names; the other screened sets were checked by count only. The screen shows no conflict with curated keywords; it does not measure precision on the 12,487,598 unreviewed entries the rule annotates. Meaning and parsimony: Transferase is the top-level enzyme class label, and the ten recorded sets each select a family of transferases (EPSP synthase, RNA polymerase, rRNA and tRNA methyltransferases, GlmU, NAD kinase, porphobilinogen deaminase, isopropylmalate synthase), so the label is true and is what the keyword is for. It is also the least informative statement available: UniProt's keyword hierarchy places 13 narrower keywords under it (Kinase, Methyltransferase, Glycosyltransferase, Nucleotidyltransferase, Acyltransferase and others), each with its own ARBA rule. Measured on all 4,603 sets, 2,661 (58%) are structurally covered by a condition set of one of those child-keyword rules, 1,196 of them by the Kinase rule ARBA00022777 alone. Keywords stack, so these sets do emit Transferase, but they restate, signature by signature, what the child rules already establish and what the keyword hierarchy implies.

Action Rationale

The first pass left the rule undecided because not every set was read. On the meaning axis no more reading is needed: a class label is coherent if the sets select members of the class, and the sample and the full-rule coverage count agree that they do. On parsimony there is a measurable defect of construction: more than half the sets duplicate sets of child-keyword rules. One step, assigning Transferase wherever a child keyword is assigned, would replace 2,661 sets and leave 1,942 for transferases that have no narrower keyword. The annotations are not wrong and nothing needs retracting; the change is a simplification. Confidence is modest because the proposal depends on ARBA being able to chain a keyword from a keyword, which was not verified, and because precision on unreviewed entries is still unmeasured.

APPROPRIATE

The one recorded taxon condition, Riboviria on the polymerase superfamily (set 21), keeps a broad superfamily signature to RNA viruses. Taxon conditions were not reviewed beyond the recorded sets.
