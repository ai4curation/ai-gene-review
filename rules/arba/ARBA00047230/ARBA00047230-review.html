Description

Assigns GO:0052629 phosphatidylinositol-3,5-bisphosphate 3-phosphatase activity to primate and eukaryotic myotubularin-family proteins through four alternative condition sets: the myotubularin-like phosphatase domain together with the protein-tyrosine phosphatase active site (Primates), and three myotubularin FunFams (Primates, Haplorrhini, Eukaryota).

Review Summary

All four live condition sets were examined. Every Swiss-Prot entry matching any set carries GO:0052629, and each set contains members annotated from experiments (for example MTMR2, MTMR3, MTMR4, MTMR6, MTMR8, MTM1, MTMR1). In set 1 the active-site condition is what separates the active myotubularins from the catalytically inactive family members: of 63 Swiss-Prot entries with IPR010569, 37 also have IPR016130, and the six human entries without it are the proteins UniProt names "Inactive phosphatidylinositol 3-phosphatase" (MTMR5, 9, 10, 11, 12, 13).

Action Rationale

Each condition set selects myotubularins with curated, mostly experimental, annotation to the rule's term, and no Swiss-Prot match lacks the term. The second condition of set 1 should stay, because dropping it would extend a catalytic activity to the inactive paralogs.
