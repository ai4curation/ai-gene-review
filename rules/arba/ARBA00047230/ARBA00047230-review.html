Description

Assigns GO:0052629 phosphatidylinositol-3,5-bisphosphate 3-phosphatase activity to primate and eukaryotic myotubularin-family proteins through four alternative condition sets: the myotubularin-like phosphatase domain together with the protein-tyrosine phosphatase active site (Primates), and three myotubularin FunFams (Primates, Haplorrhini, Eukaryota).

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: all four live condition sets were examined. Every Swiss-Prot entry matching any set carries GO:0052629 (phosphatidylinositol-3,5-bisphosphate 3-phosphatase activity), and each set contains members annotated from experiments (MTMR2, MTMR3, MTMR4, MTMR6, MTMR8, MTM1, MTMR1). In set 1 the active-site condition IPR016130 (Protein-tyrosine phosphatase, active site) is what separates the active myotubularins from the catalytically inactive family members. Meaning and parsimony: the four sets select one biological unit, the catalytically active myotubularins, and the consequent is a leaf term (no descendants) that experiments place on the members themselves, so the rule says the most informative thing that is true of what it selects. Sets 2 and 3 mostly repeat set 1 (239 of 284 and 149 of 157 of their UniProtKB matches also match set 1), which is some redundancy but not sets that do nothing. Three of the four sets are restricted to primates, which follows where the human annotations are and not where the enzyme exists.

Action Rationale

Each condition set selects active myotubularins with curated, mostly experimental, annotation to the rule's own term; the term cannot be made more specific; and no simpler construction is available, because the family domain alone would include the inactive paralogs. The primate restrictions cost coverage and do not make any annotation wrong.

Assessments

ACCEPTABLE

Set 1 (domain plus active site, Primates) matches 660 UniProtKB entries. Set 2 matches 284, of which 45 are not in set 1; set 3 matches 157, of which 8 are not in set 1; within primates set 4 adds nothing to set 1 (0 entries) but outside primates it is the only set that fires (3,192 eukaryotic entries) (UniProtKB queries, November 2026). So sets 2 and 3 are largely, not wholly, redundant, and their extra matches are entries that lack the active-site signature and should be looked at before the sets are relied on. rules/arba/_interpro2go.txt maps none of the rule's InterPro entries to the consequent (IPR016130 maps only to GO:0016311, dephosphorylation), so no single InterPro2GO line replaces the rule.

STRONG

Curated GO annotations on matched Swiss-Prot entries: Q13614 (MTMR2) GO:0052629 EXP PMID:21372139; Q13615 (MTMR3) GO:0052629 IDA PMID:11676921; Q9NYA4 (MTMR4) GO:0052629 IDA PMID:20736309; Q13496 (MTM1) GO:0052629 EXP PMID:14722070; Q9Y217 (MTMR6) GO:0052629 EXP PMID:22647598 (QuickGO, November 2026).

APPROPRIATE

The experimental annotations on the matched proteins are to GO:0052629 (phosphatidylinositol-3,5-bisphosphate 3-phosphatase activity) itself, and the term has no descendants.

TOO_NARROW

Sets 1 and 2 are restricted to Primates and set 3 to Haplorrhini, but active myotubularins are found across eukaryotes: 26 Swiss-Prot entries outside primates match the conditions of set 1, among them yeast Ymr1 (P47147). The restriction reflects where the experimental annotations are (human proteins), not where the enzyme occurs. This is narrow coverage, not wrong annotation; only set 4 (Eukaryota) reaches other lineages, and only for the MTMR3/MTMR4 subfamily.
