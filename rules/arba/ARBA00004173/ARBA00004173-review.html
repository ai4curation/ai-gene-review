Description

Assigns the UniProt subcellular location Mitochondrion (SL-0173) through 1,525 alternative condition sets built from CATH FunFam, InterPro and PANTHER signatures, each with a taxon condition. UniProt converts the location to GO:0005739 (mitochondrion) by GO_REF:0000044.

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: all 1,525 live condition sets were screened with two UniProtKB queries each (2026-11-10): the Swiss-Prot entries that match the whole conjunction, and how many of them have the subcellular location Mitochondrion (SL-0173). In 1,513 sets every Swiss-Prot match has the location, in 11 some do not (sets 43, 209, 251, 365, 378, 456, 484, 549, 718, 1084, 1384) and set 1312 matches no Swiss-Prot entry. Three sets match plastid-encoded ATP synthase subunits curated to the chloroplast thylakoid membrane (set 251, 33 of 41 matches; set 456, 5 of 10; set 484, 7 of 12). Set 789 transfers a location that mouse and human SCP2 entries record for the short SCP2 isoform to full-length SCPx proteins, which the entries record as peroxisomal; Drosophila ScpX (Q9VJ43) receives Mitochondrion from it. Sets 1384, 1084 and 365 have minority matches located elsewhere. Precision on the 562,320 unreviewed entries the rule annotates was not measured. Meaning and parsimony: the rule assigns an organelle, and an organelle is an informative location in its own right. The 14 recorded sets select recognisable units (mitochondrially encoded cytochrome b, mitochondrial ABC transporters, HIG1 proteins, lipoyl synthase, ATP synthase subunits), and the complete screen shows that in 1,513 of 1,525 sets all reviewed matches are mitochondrial, so the sets do select what the label names. Where a unit has a known sub-compartment the rule stops at the organelle, but that is the level the rule is for, and only 47 of the 1,525 sets are covered by an ARBA rule for a mitochondrial sub-location. No set is subsumed by another. The defects are therefore the specific sets already identified, not the design of the rule.

Action Rationale

Specific condition sets are defective. Sets 251, 456 and 484 match chloroplast ATP synthase subunits, and set 789 transfers a location that the source entries record for a different isoform than the one the set detects. These four sets should be removed or narrowed; sets 1384, 1084 and 365 need a closer look. The meaning and parsimony check adds no new defect: the label is at the right level for a location rule and the sets are not redundant with one another. The rule as a whole is kept.

Assessments

ACCEPTABLE

Checked on the 1,525 sets downloaded 2026-11-12. No set's signatures are a subset of another set's with compatible taxon conditions, so no set is structurally idle. 47 sets are covered by a set of an ARBA rule that assigns a mitochondrial sub-location (Mitochondrion membrane, inner membrane, outer membrane, intermembrane space or matrix), among the recorded sets 1, 251 and 378; 108 sets are covered by the keyword rule ARBA00023128 (KW-0496 Mitochondrion), which states the same fact as a keyword. Set 1312 matches no Swiss-Prot entry. Every set has a taxon condition and 815 are a single signature. rules/arba/_interpro2go.txt maps 69 InterPro entries to GO:0005739; they were not compared with the rule's 1,525 sets.

APPROPRIATE

The rule emits the UniProt location Mitochondrion (SL-0173), which UniProt converts to GO:0005739 (mitochondrion); for example Q9VJ43 carries GO:0005739 IEA GO_REF:0000044 assigned by UniProt. The organelle term is an informative location in itself and is the level a location rule of this kind is meant to assert; sub-compartment locations are assigned by separate ARBA rules for the few sets where signatures support them.

APPROPRIATE

All 1,525 sets carry a taxon condition, either a positive eukaryotic clade or NOT Bacteria, NOT Archaea, NOT Viruses, which is where mitochondria exist. The three plant-clade sets that fail (251 rosids, 456 Liliopsida, 484 Solanaceae) fail because plants have plastid copies of the same subunits, a problem of the signatures, not of the taxon.
