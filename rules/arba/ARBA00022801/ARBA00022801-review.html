ARBA rule assigning the UniProt keyword Hydrolase (KW-0378) through 4171 alternative condition sets built from InterPro, PANTHER and taxon conditions.

Review Summary

Accuracy: all 4171 served condition sets were compared with Swiss-Prot keyword use. 4170 sets match reviewed entries, and in all but one of them every reviewed match carries the keyword Hydrolase (130233 of 130239 reviewed matches summed over sets). The exception is set 2549, two FunFams whose reviewed members are translin: none of the six carries the keyword, yet the 1160 unreviewed translins it matches all receive Hydrolase from this rule. One set (389) matches no UniProtKB entry at all. The 44 sets recorded here in detail (four from the first pass and a random sample of 40) all agree with Swiss-Prot. Meaning and parsimony: the rule does what its label says, selecting hydrolase families one by one and giving them the class-level keyword. The keyword is broad by design; UniProt keywords are hierarchical and an entry carries the class keyword beside a narrower one, so the 1759 sets that are also condition sets of rules for narrower keywords (Protease 689, Nuclease 355, Glycosidase 284, Helicase 201, Protein phosphatase 141 and others) still do work.

Action Rationale

On reviewed evidence the rule is accurate in every set but one and coherent as a class-level keyword rule; its size is the size of the enzyme class. The specific defects are set 2549, which labels translin a hydrolase against curated usage, and set 389, which cannot fire. Confidence is moderate because the check is the keyword of reviewed entries, not an inspection of the 10 million unreviewed entries the rule annotates.

Assessments

ACCEPTABLE

Each signature is used in exactly one set (3300 FunFam, 2049 InterPro and 610 PANTHER conditions; 2940 sets are a single signature) and no set is contained in another by its conditions. 4170 of 4171 sets match reviewed entries (median 7 per set); one matches none: set 389, which matches no UniProtKB entry at all because its taxon condition (Flaviviridae) no longer contains the hepatitis C virus proteins its signature selects. 1759 sets share their signatures with a set of a rule for a narrower keyword under Hydrolase; because an entry carries both keywords, these are not dead sets. Overlap between sets by matched proteins was not measured.

APPROPRIATE

478 of 4171 sets carry a taxon condition. Hydrolases occur in all life; in the 44 sets examined in detail no restriction excluded a lineage whose reviewed members carry the keyword. Not assessed set by set beyond that.
