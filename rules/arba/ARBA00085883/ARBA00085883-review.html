Description

Assigns GO:0030167 proteoglycan catabolic process through four alternative condition sets of CATH FunFams: beta-galactosidase (Euarchontoglires), alpha-L-iduronidase (no taxon condition), beta-hexosaminidase (Mus) and N-acetylglucosamine-6-sulfatase (Eukaryota).

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: all four live condition sets were examined. The Swiss-Prot matches of every set carry a descendant of GO:0030167 (proteoglycan catabolic process) with experimental evidence: beta-galactosidase GLB1 (keratan sulfate, IMP), alpha-L-iduronidase (dermatan sulfate and heparan sulfate, IDA and IMP), mouse HEXA and HEXB (dermatan sulfate, IGI) and N-acetylglucosamine-6-sulfatase (heparan sulfate, IDA and IMP). No annotation the rule could make is false. Meaning and parsimony: the rule is an umbrella over four lysosomal glycosidase and sulfatase families, each of which has a curated child term naming the glycosaminoglycan it degrades. Those child terms are already asserted by other ARBA rules using the same condition sets (ARBA00087463, ARBA00085487, ARBA00085492), so all four sets are covered, and QuickGO holds no annotation attributed to this rule.

Action Rationale

The split that the biology calls for has already been made upstream: each of the four sets is matched exactly by a rule asserting a more specific term. Because UniProt keeps only the most specific ARBA term, this rule emits nothing (0 annotations in QuickGO) and can be removed without losing an annotation.

Assessments

REDUNDANT

All four sets are duplicated in rules for descendant terms (rest.uniprot.org/arba search, 2026-11-12): set 1 equals the single set of ARBA00087463 (GO:0042340 (keratan sulfate proteoglycan catabolic process)); sets 2 and 4 equal the two sets of ARBA00085487 (GO:0030200 (heparan sulfate proteoglycan catabolic process)); set 3 equals a set of ARBA00085492 (GO:0030209 (dermatan sulfate proteoglycan catabolic process)). QuickGO annotation search withFrom=ARBA:ARBA00085883 returns 0 annotations, against 96, 764 and 117 for the three covering rules.

STRONG

Curated GO annotations (QuickGO, November 2026): P16278 (GLB1) GO:0042340 IMP PMID:31720227; P35475 (IDUA) GO:0030209 IDA PMID:24036510; HEXA_MOUSE and HEXB_MOUSE GO:0030209 IGI PMID:11707436; P15586 (GNS) GO:0030200 IDA PMID:15595925. GO:0042340, GO:0030209 and GO:0030200 are descendants of GO:0030167.

TOO_BROAD

GO:0030167 (proteoglycan catabolic process) is the common parent of the terms the matched proteins are experimentally annotated to (GO:0042340 (keratan sulfate proteoglycan catabolic process), GO:0030209 (dermatan sulfate proteoglycan catabolic process), GO:0030200 (heparan sulfate proteoglycan catabolic process)), and each of those is asserted for the same proteins by its own rule.

TOO_NARROW

Set 3 is restricted to the genus Mus and set 1 to Euarchontoglires, although beta-hexosaminidase and beta-galactosidase are lysosomal enzymes of all vertebrates and beyond; sets 2 and 4 are unrestricted or Eukaryota. The narrow taxa follow where the experimental annotations are (mouse HEXA and HEXB, human and mouse GLB1), not the biology. This is narrow coverage, not wrong annotation, and it is inherited by the covering rules.
