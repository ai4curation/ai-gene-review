Description

ARBA rule assigning GO:1990849 vacuolar localization to eukaryotic proteins that carry two CATH FunFams named for pleckstrin homology domain-containing family M member 1 (PLEKHM1).

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: the single condition set matches 116 UniProtKB proteins, all metazoan PLEKHM1 orthologues; human and mouse PLEKHM1 are experimentally annotated to GO:0032418 (lysosome localization), an is_a child of the rule's term GO:1990849 (vacuolar localization), so the annotation is true but one level too general. Meaning and parsimony: the rule selects one family, and the informative statement about it is lysosome localization. That statement is already made by another served rule, ARBA00084220, whose only condition set is the same two FunFams with the same Eukaryota condition. UniProt keeps the most specific ARBA term, and QuickGO shows 116 annotations from ARBA00084220 and none from ARBA00089175, so this rule emits nothing.

Action Rationale

The first pass proposed replacing the consequent with GO:0032418 (lysosome localization). That replacement already exists as ARBA00084220 with an identical condition set, so modifying this rule would only duplicate it. The rule is covered in its one set by a more specific rule and produces no annotation; it should be retired.
