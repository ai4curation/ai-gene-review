Description

ARBA rule assigning the subcellular location "Cytoplasmic vesicle, secretory vesicle, acrosome" through 38 alternative condition sets, each a conjunction of family signatures with a taxon condition.

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: all 38 condition sets were turned into UniProtKB queries. In every set, every reviewed match carries a curated acrosome location, so the rule reproduces Swiss-Prot within animals. One set does not stay within animals: set 10 (MORN repeat-containing protein 3) is restricted only to Eukaryota minus five plant, fungal and amoebozoan taxa, and it puts the acrosome location on 333 proteins of trypanosomatids, alveolates and other protists, which have no acrosome. Meaning and parsimony: each set selects one family, and the shared statement is a location in an animal sperm organelle. For about fifteen sets the family is a widely expressed protein (dihydrolipoyl dehydrogenase, CDC42, RAB2, RAB6A, RACGAP1, golgin A1, the epithelial sodium channel alpha subunit, CD46 and others) whose acrosome location is a secondary site reported in sperm; the statement is true of the reviewed members but is not what those families are about. Set 5 adds no protein beyond set 19.

Action Rationale

The rule is coherent as a location rule and agrees with curated locations for reviewed proteins, but it has specific defects: a taxon condition that does not follow the biology and produces wrong annotations for named non-metazoan proteins, and one set that does no work. These are fixable without touching the rest of the rule.

Assessments

REDUNDANT

Each signature is used in one set only and no set is contained in another by its conditions. By matched proteins (UniProtKB 2026_04), set 5 has 338 entries and none outside set 19; no other set without a PANTHER subfamily condition is fully contained in the rest. Pairs of sets for the same family overlap heavily without being contained (set 16 has 6 of 194 entries outside set 2; set 18 has 13 of 191 outside set 4; set 15 has 5 of 702 outside set 1). The five negated taxon conditions repeated in 19 sets exclude nothing that a single Metazoa condition would not.

TOO_BROAD

The acrosome is an organelle of animal sperm. Nineteen sets use Eukaryota minus Gnetales, Fungi, Magnoliopsida, Zygnematales and Dictyostelium, which leaves protists, algae and non-flowering plants in scope; for set 10 that admits 333 non-metazoan proteins. The other 19 sets use animal clades from Metazoa down to Murinae; the narrow ones (Muridae, Murinae, Myomorpha, Rodentia, Glires) follow where the reviewed proteins are, which is narrow coverage, not wrong annotation.
