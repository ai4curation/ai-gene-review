Description

Assigns GO:0004175 (endopeptidase activity) through 104 alternative condition sets built from InterPro entries, PANTHER families and CATH FunFams, most with a taxon. The sets cover caspases, papain-like and legumain cysteine peptidases, aspartic peptidases, proteasome subunits, signal peptidases, trypsin- and subtilisin-like serine peptidases and several metallopeptidase families.

Review Summary

All 104 live condition sets were checked against Swiss-Prot. They match 1063 reviewed entries in total and every one carries GO:0004175 or a descendant, 630 by manual evidence. One set is weakly founded: set 14 is the single InterPro entry IPR003675, which matches 56399 unreviewed entries. Of its 40 reviewed matches only 10, all CAAX prenyl protease 2 orthologues, have a manual annotation; the other 30, which include lysostaphin resistance protein A and proteins named as uncharacterised, carry the term only from this rule.

Action Rationale

Set 14 extends an activity shown for CAAX prenyl protease 2 to a whole domain family whose other reviewed members have no independent support for it. The set should be narrowed to the characterised subfamily. No defect was found in the other 103 sets, which were checked by counts only. The counts are from Swiss-Prot, which is also what ARBA learns its rules from, so they show the condition sets are coherent rather than giving an independent error rate for unreviewed entries.
