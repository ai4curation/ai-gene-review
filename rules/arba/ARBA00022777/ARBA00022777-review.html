Every screened set matches at least one Swiss-Prot entry. No screened set has a Swiss-Prot match without the keyword. 10 sets are recorded in the rule block with official signature names; the other screened sets were checked by count only and their signatures were not read. 171 of the 1,392 sets have a taxon condition. ARBA rules are mined from Swiss-Prot annotation, so this screen shows that no screened set conflicts with curated keywords; it does not measure precision on the 3,762,398 unreviewed entries the rule annotates.

Action Rationale

The rule was not read set by set: 10 of 1,392 condition sets are recorded and 1,392 were screened by count. Nothing found argues against the rule. The keyword Kinase is defined by UniProt as: Enzyme that catalyzes the transfer of phosphate (phosphoryl or pyrophosphoryl transfer) usually from ATP to a second substrate. It is a class label, so diversity among its members is expected, and in every screened set all Swiss-Prot matches carry it. UniProt maps KW-0418 to GO:0016301 kinase activity. A verdict on the whole rule needs every set to be read and precision on unreviewed entries to be measured.
