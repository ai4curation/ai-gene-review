Description

Assigns GO:1990845 (adaptive thermogenesis) to Mus proteins that match both CATH FunFams 1.10.287.70:FF:000074 and 1.25.40.20:FF:000018, which are named for transient receptor potential cation channel subfamily V member 1.

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: the live rule has one condition set, two TRPV1-named CATH FunFams in Mus. Its Swiss-Prot matches are mouse Trpv1 (Q704Y3) and Trpv4 (Q9EPK8); both are annotated by IMP to GO:0002024 (diet induced thermogenesis), an is_a/part_of descendant of GO:1990845 (adaptive thermogenesis), so the annotation is true of them. Seven unreviewed Mus entries also match. Meaning and parsimony: the set selects one unit, the TRPV1/TRPV4 channels, and curated annotation puts the more specific GO:0002024 on both, so the consequent is an umbrella over a unit that has a better term. ARBA00087880 asserts GO:0002024 from a condition set that covers this one, and UniProt keeps only the most specific ARBA term, so this rule emits nothing: QuickGO holds no annotation with ARBA:ARBA00089174 as its source (2026-11-12). The Mus restriction follows where the knockout annotations are, not where the channels exist.

Action Rationale

The rule's only condition set is covered by ARBA00087880, which asserts the descendant GO:0002024 (diet induced thermogenesis), the term curators chose for both reviewed matches. The rule therefore produces no annotation and adds nothing a retained rule does not already say more precisely. It is not wrong; it is dead weight. Confidence is limited because coverage is a structural test on signatures and the zero count is one QuickGO snapshot.
