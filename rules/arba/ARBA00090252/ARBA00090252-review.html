Description

Assigns GO:0000055 (ribosomal large subunit export from nucleus) to two groups of budding-yeast ribosomal proteins: ubiquitin-ribosomal protein eL40 fusions in Saccharomycotina, and ribosomal protein uL1 (L10a) in Saccharomycetes. Each condition set requires two CATH FunFams and a taxon.

Review Summary

Both live condition sets were examined. Set 2 (uL1) is supported: Saccharomyces cerevisiae RPL1A and RPL1B carry GO:0000055 with IMP evidence from SGD. Set 1 (eL40) has no manual support: its two reviewed matches, RPL40A and RPL40B, carry the term only through this rule. Nothing checked shows the eL40 annotation to be wrong, so the rule is left undecided on that set.

Action Rationale

Set 2 rests on a curated experimental annotation of the yeast protein. Set 1 rests on no manual annotation that could be found, and no published result was checked that either supports or excludes a role for eL40 in export. A decision on set 1 needs the yeast eL40 literature to be read.
