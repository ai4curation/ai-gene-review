Description

Assigns GO:0000055 (ribosomal large subunit export from nucleus) to two groups of budding-yeast ribosomal proteins: ubiquitin-ribosomal protein eL40 fusions in Saccharomycotina, and ribosomal protein uL1 (L10a) in Saccharomycetes. Each condition set requires two CATH FunFams and a taxon.

The domain overlap table is not shown for this review. It is drawn from a cached analysis of the rule's condition sets, and the cache does not match the sets recorded here.

Review Summary

Accuracy: both live condition sets were examined. Set 2 (ribosomal protein uL1 in Saccharomycetes) is supported: Saccharomyces cerevisiae RPL1A and RPL1B carry GO:0000055 (ribosomal large subunit export from nucleus) with IMP evidence from SGD. Set 1 (ubiquitin-eL40 fusion proteins in Saccharomycotina) has no manual support: RPL40A and RPL40B carry the term only through this rule. Meaning and parsimony: the two sets select two unrelated ribosomal proteins, and the consequent fits only one of them. SGD curates eL40 from the paper that studied its role in 60S biogenesis to GO:0000027 (ribosomal large subunit assembly), which is not under the consequent, and did not annotate export. The rule is small and has no redundant set, but set 1 asserts a process that the curators who read the eL40 literature chose not to assert.

Action Rationale

Set 2 is a coherent unit with a curated experimental annotation to the consequent. For set 1 the best curated term lies outside the consequent (P0CH08, GO:0000027 IMP PMID:22995916, SGD), and the only source of GO:0000055 on eL40 is this rule, so the set should be removed or re-pointed. A rule that then holds one protein in one class is a narrow but sound statement.

Assessments

ACCEPTABLE

Two sets, each two FunFams and a taxon, matching 2 and 4 reviewed and 83 and 61 unreviewed entries. Neither is covered by another rule. The defect is set 1's consequent, not surplus conditions.

MISMATCHED

Appropriate for set 2. For set 1 the curated process is GO:0000027 (ribosomal large subunit assembly), a different branch.

APPROPRIATE

Saccharomycotina and Saccharomycetes bound the sets to the lineage of the yeast proteins on which the evidence was obtained. uL1 and eL40 are universal in eukaryotes, so this is narrow coverage that follows the training annotation, and is the cautious choice for a phenotype-derived process term.
