## Abstract

1. Bioinformatics. 2022 Oct 31;38(21):4978-4980. doi:

AEON.py: Python library for attractor analysis in asynchronous Boolean networks.

Beneš N(1), Brim L(1), Huvar O(1), Pastva S(1), Šafránek D(1), Šmijáková E(1).

Author information:
(1)Faculty of Informatics, Masaryk University, Brno 602 00, Czech Republic.

SUMMARY: AEON.py is a Python library for the analysis of the long-term behaviour
in very large asynchronous Boolean networks. It provides significant
computational improvements over the state-of-the-art methods for attractor
detection. Furthermore, it admits the analysis of partially specified Boolean
networks with uncertain update functions. It also includes techniques for
identifying viable source-target control strategies and the assessment of their
robustness with respect to parameter perturbations.
AVAILABILITY AND IMPLEMENTATION: All relevant results are available in
Supplementary Materials. The tool is accessible through
https://github.com/sybila/biodivine-aeon-py.

online.
