# PyBoolNet: a python package for the generation, analysis and visualization of boolean networks.
**Authors:** Klarner H, Streck A, Siebert H
**Journal:** Bioinformatics (2017)
**DOI:** [10.1093/bioinformatics/btw682](https://doi.org/10.1093/bioinformatics/btw682)

## Abstract

1. Bioinformatics. 2017 Mar 1;33(5):770-772. doi: 10.1093/bioinformatics/btw682.

PyBoolNet: a python package for the generation, analysis and visualization of
boolean networks.

Klarner H, Streck A, Siebert H.

MOTIVATION: The goal of this project is to provide a simple interface to working
with Boolean networks. Emphasis is put on easy access to a large number of
common tasks including the generation and manipulation of networks, attractor
and basin computation, model checking and trap space computation, execution of
established graph algorithms as well as graph drawing and layouts.
RESULTS: P y B ool N et is a Python package for working with Boolean networks
that supports simple access to model checking via N u SMV, standard graph
algorithms via N etwork X and visualization via dot . In addition, state of the
art attractor computation exploiting P otassco ASP is implemented. The package
is function-based and uses only native Python and N etwork X data types.
AVAILABILITY AND IMPLEMENTATION: https://github.com/hklarner/PyBoolNet.
