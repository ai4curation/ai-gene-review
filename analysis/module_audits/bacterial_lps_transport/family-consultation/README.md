## Module and capacity consequences

The source-qualified ECOLI/PSEPK complete panels remain supported. The three Neisseria proteins are a partial panel, not a complete extractor/bridge. Capacity must require LPS/LOS-bearing diderm context, exact compatible roles/partners and positive member-level evidence in addition to family identity. Explicit controls should fail for non-LPS diderms, generic ABC motors, taxon-only evidence, a repeated F replacing G, mismatched interfaces, and isolated partial panels. Conditional suppressor bypass is outside the encoded canonical profile rather than biologically impossible. The root and capacity consultant own implementation; this consultation does not edit module or capacity code.
