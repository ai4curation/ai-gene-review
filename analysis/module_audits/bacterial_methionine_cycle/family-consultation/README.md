# Methionine-cycle family consultation

This bounded review covers PTHR11964 (MetK), PTHR23420 (AhcY), PTHR46832 (Pfs), PTHR35799 (LuxS), PTHR45833 (MetH-related) and PTHR30519 (MetE-related). It changes no gene, module, project, existing provider, publication or raw family source. The five prior reviews and their source hashes were captured before editing in `baseline.json`. Only the missing LuxS PAINT slice was normally acquired; no existing slice was refreshed.

## Scientific decisions

- **MetK:** retain SAM-synthesis chemistry. The official root encompasses conserved catalytic MetK/MAT proteins; the experimentally curated E. coli reaction and KT2440 HAMAP assignment independently support the chemistry. Variable oligomer composition is not a universal bacterial requirement. The previously omitted vertebrate MAT-complex PAINT row is additive and lineage scoped.
- **AhcY:** retain canonical SAH hydrolysis and explicitly represent the existing AHCYL IKR loss as `LOSS_SUPPORTED`. Mouse AHCYL1 recombinant assays, as recorded with PMID12525476 in curated UniProt, directly support the negative activity judgment; rat/human transfer is distinguished. The actual loss subtree contains SF0 as well as SF2/SF3. Therefore the former SF0-inclusive universal catalytic and cycle grants become `UNRESOLVED`. The catalytic loss is still a live machine-readable PAINT judgment, not only a historical archive. The positive ancestor is interpreted together with its descendant loss. The process assertion has no corresponding raw process-loss row, so its universal placement is separately unresolved.
- **Pfs:** E. coli directly supports both SAH and MTA nucleosidase reactions. The actual root also includes five SF2 MqnB representatives. Curated Streptomyces MqnB evidence supports futalosine hydrolysis; different primary chemistry alone does not establish absence of all secondary SAH/MTA activity. Root placement is unresolved. The inherited SF1-only scope is also withdrawn: production SUBFAMILY_ONLY enforces an activity exclusion for every other subfamily, which the MqnB evidence does not establish. Canonical Pfs positives remain explicitly supported; no speculative loss node is assigned.
- **LuxS:** create the missing review and represent the two actual bacterial PAINT rows. The exact S-ribosylhomocysteine lyase reaction is supported; DPD production is not a universal quorum-sensing response. GO0009372 requires detection and a population-dependent response, not simply precursor synthesis. No new signaling grant is made.
- **MetH-related family:** withdraw the universal complete-MetH grant. The official tree includes SF2 YitJ/MetF-like fusions; Q748M7 has PF02574 homocysteine-methyltransferase and PF02219 MTHFR domains. Its official SF2 assignment remains current. O06745 is placed in this tree but current UniProt assigns PTHR11103; both source facts are preserved, with no override or silent remapping. Shared homocysteine chemistry is not proof of the complete canonical folate/B12 mechanism. This is a scope uncertainty, not a secondary-activity negative assay. Unrelated localization and folate-process PAINT assessments are preserved.
- **MetE-related family:** withdraw universal folate-polyglutamate chemistry. PMID33534785 experimentally distinguishes MesD/MesX from canonical MetE, using S. koreensis genetics and heterologous complementation, not purified donor identification in KT2440. Official Q6F6Z8 and Q88JF1 are catalytic-barrel proteins classified in PTHR30519; Q88E31 is a separate N-terminal-only barrel. A hypothetical KT2440 split partnership is not established. SF0 itself spans short and full-length architectures in the MSA. The prior GO0008705 pruning rationale incorrectly equated the term with cobalamin dependence: the actual definition specifies a monoglutamate folate reaction. The full PMC text of PMID16618097 independently confirms that its Introduction reports a canonical E. coli monoglutamate restriction, citing earlier work; its own kinetic experiments use triglutamate. The stable externally acquired scope excerpt and provenance from the E. coli consultation are cited, because the normal publication cache is abstract-only. This is not described as a new negative assay in that paper, nor as a negative for every plant seed. The universal node remains unresolved without erasing canonical MetE positives. The raw rosid chloroplast row is additive and is not transferred to bacteria.

## Tree, alignment and assay limits

`acquisition.json`, `additional-acquisition.json`, `msa-acquisition.json` and `sih-acquisition.json` record exact official URLs and source hashes. The six official PANTHER trees contain 364, 255, 36, 15, 73 and 185 leaves respectively. All leaf alignment records are checked by `check_phylogeny.py`; full MSA snapshots include reconstructed ancestor sequences, which are not treated as observed proteins. The P13009/Q748M7 alignment shows distinct domain coverage, independently consistent with the official domain architecture. No catalytic residue discriminator is invented.

Q6F6Z8, Q88JF1 and Q88E31 are absent from the downloaded PANTHER tree/MSA despite official family classification. Consequently no exact PAINT pruning point is claimed for those targets. Classification, topology and experimental activity are separate evidence types. Raw date, seed, qualifier/polarity and taxon data are never inferred from donor counts or a target appearing among its own seeds.

The full cached PMID33534785 is primary research. Its MetE/MesD statements and the limits of S. koreensis complementation were read in full; target inference uses independently acquired official domain/sequence context. Other catalytic statements in this consultation are explicitly curated UniProt evidence, with original PubMed or HAMAP/PIRNR evidence codes preserved in their JSON snapshots. They are not relabeled as newly read target assays. The Q80SW1 negative is directly curated against PMID12525476; B5DFN2's corresponding negative is marked by similarity. Existing publication caches were not altered.

Thermotoga O51933 is officially PTHR23420:SF0. The separate literature consultation identifies primary17603473 evidence for dual SAH/SIH hydrolysis. That is compatible with canonical SAH positivity and does not justify transferring an SIH-specific activity to every AhcY. No archaeal exemplar is relabeled bacterial and no family-wide SIH grant is added here. Native flux and pathway completeness require additional context beyond an enzyme's biochemical capacity.

## Preservation and checks

`check_preservation.py` verifies all 17 original PAINT assertion payloads and their order, seven unrelated complete node objects, original subfamily IDs/labels/members, all protected source bytes and all old history bytes. Only the targeted SF0 descriptions are clarified; neither their identifiers nor members are changed. Five raw assertions are represented additively (including two in the new LuxS review). The root baseline contains 37 protected sources. No source annotation is created or retired by this family consultation.

`preservation.json` contains the exact changed-judgment ledger, deterministic quote ledger and input hashes. Every local quote is checked against its actual source with the production matcher. The generic reference validator skips local files, so its skipped count is not treated as verification; the explicit local-source check supplies that coverage. Its PubMed quotes are checked with the production publication validator. A zero-conflict family/gene crosscheck does not prove a universal scope: its output reports how many comparisons were actually made, and unresolved family grants intentionally avoid asserting unsupported negatives.

Run `uv run python .../check_phylogeny.py`, `uv run python .../check_preservation.py`, and `uv run python .../run_checks.py` using this directory's full relative path. Focused schema, terms, references, family/gene crosscheck, Ruff, generated histories and member/PAINT grounding are recorded separately. One incremental member refresh is owned by this consultation; no full-corpus validation is run. The final handoff freezes exact files after all checks finish. Family reviews have no separate HTML renderer.

Module selector recommendation: MetK and LuxS support the exact family reaction grants. For canonical MetE, complete MetH, AhcY and Pfs, use precise free-text role/architecture with positively supported representative members and omit the PANTHER term as an activity license; retain actual classification only as context. SUBFAMILY_ONLY is an exclusionary production rule, not a positive-only list, so it must not be used to hide unknown secondary activities. This limitation is distinct from protein-family membership.
