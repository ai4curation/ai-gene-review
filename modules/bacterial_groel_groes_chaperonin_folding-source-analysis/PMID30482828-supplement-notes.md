# Caulobacter construct and strain checks

PMID:30482828 official supplementary Table S2 identifies the Caulobacter background as CB15N, so the NA1000/CB15N reference proteome is used here, not CB15. It lists recombinant CcGroEL, CcGroES and CcCnoX expression constructs in BL21. Text S1 describes untagged CcGroEL and CcCnoX preparations and C-terminally His-tagged CcGroES. These are Caulobacter proteins expressed in E. coli, not E. coli refolding factors.

The main Methods explicitly describes the Caulobacter GroEL14/ES7 system in citrate-synthase recovery after CcCnoX capture. This supports biochemical cooperation; it does not resolve direct client transfer kinetics or prove stable CnoX binding to the Caulobacter cage.
